## ASSUMPTION ทั้งหมด (มีคอมเมนต์ `// ASSUMPTION:` ในโค้ด)

1. **ค่าชั่วคราว รอคำตอบ** `StepsRules.stepsPerTap = 1000` — ก้าวต่อการกด 1 ครั้งไม่มีใน game-rules (ui-spec Q-2) — steps_rules.dart
2. AC-2 vs AC-4 ขัดกัน — ตีความตาม brief.md §2: ตั้งครั้งแรก → มีผลทันที; เปลี่ยน 00:00–04:59 → มีผลทันที; เปลี่ยน 05:00–23:59 → มีผล 05:00 รอบวันถัดไป — steps_logic.dart `goalAppliesImmediately`
3. ทุกการบันทึกเป้าหมายที่สำเร็จหักโควต้า รวมการตั้งครั้งแรก (game-rules §3) — steps_logic.dart `saveGoal`
4. EC-3 ไม่มี network time → ใช้ `max(lastSeenAt, now)` ไม่รีเซ็ต/ไม่ย้อนรอบวัน/ไม่คืนโควต้า — steps_logic.dart `effectiveNow`
5. EC-4 multi-device ทำไม่ได้แบบ offline — ไม่มีโค้ด sync (ข้อมูลอยู่เครื่องเดียว)
6. ตรวจรอบวันทุก 1 วินาทีขณะเปิด S-1 ค้าง (EC-5) — screens/steps_dashboard_screen.dart
7. % Goal แสดงทศนิยมสูงสุด 2 ตำแหน่งแบบตัดทิ้ง ตัดศูนย์ท้าย (ui-spec Q-7) — steps_logic.dart `formatPercent`
8. Toast 2 วินาทีเท่า water (Q-8) — steps_rules.dart `toastSeconds`
9. ค่าเฉลี่ยทศนิยม 1 ตำแหน่ง, หน่วย ก้าว/แก้ว/ก้าว/วัน/วัน (Q-10) — steps_rules.dart
10. ตัวหารค่าเฉลี่ย = จำนวนวันที่มีก้าว > 0 (แนวเดียวกับ DECIDED ของ water) — steps_logic.dart `monthlyReport`
11. "วันที่ทำเป้าหมายสำเร็จ" เทียบกับเป้าหมายที่มีผลในวันนั้น (เก็บใน `DailyStepsRecord.goal`) — steps_logic.dart
12. S-3 "ว่าง" = ก้าวรวม 0 และน้ำรวม 0 ในเดือนนั้น — steps_models.dart `MonthlyStepsReport.isEmpty`
13. บันทึก PNG ลงโฟลเดอร์ Documents ของแอป (path_provider) ไม่ใช่ Gallery — steps_external.dart `FileStepsReportExporter`
14. export สำเร็จไม่แสดงข้อความ (Q-14) — screens/steps_monthly_report_screen.dart
15. Pop-up สิทธิ์ (Q-4) ใช้ข้อความเสนอใน ui-spec; ไม่ trigger จริงใน MVP — เปิดได้ด้วย `controller.trackingStatus`; ปุ่ม 「ไปที่ Settings」 ปิด Pop-up + เรียก `onOpenSettings` (ค่าเริ่มต้นไม่ทำอะไร เพราะไม่เพิ่ม package เปิด Settings) — screens/steps_dashboard_screen.dart
