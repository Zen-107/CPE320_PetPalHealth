# Requirements: บันทึกการกินน้ำ (water)

> สถานะ: พร้อมรีวิว · ผู้เขียน: Product agent · ผู้ตรวจ: เพื่อน A · อ้างอิง Issue: #101

## 1. สรุปฟีเจอร์
ฟีเจอร์บันทึกการกินน้ำช่วยให้ผู้ใช้สามารถติดตามปริมาณการดื่มน้ำในแต่ละวันผ่านแอปพลิเคชัน PetPal Health โดยเชื่อมโยงกับการแสดงผลหลอดพลังงานและอารมณ์ของสัตว์เลี้ยง เพื่อสร้างแรงจูงใจในการรักษาสุขภาพ พร้อมระบบป้องกันการกดบันทึกถี่เกินไป (Anti-Spam) และการสรุปผลรายเดือน

## 2. ตารางแสดงสถานะสัตว์เลี้ยงตามปริมาณน้ำ (Pet Status Mapping)
| จำนวนแก้วน้ำ | เปอร์เซ็นต์หลอดพลังงาน | สถานะและอารมณ์ของสัตว์เลี้ยง |
|---|---|---|
| 0 - 3 แก้ว | 0% - 37.5% | เหี่ยวเฉา ป่วย ใกล้ตาย |
| 4 - 6 แก้ว | 50% - 75% | เริ่มเพลีย อ่อนแรง แลบลิ้น |
| 7+ แก้วขึ้นไป | 87.5% - 100%+ | สดชื่น ร่าเริง มีความสุข |

## 1. สรุปฟีเจอร์
ฟีเจอร์บันทึกการกินน้ำช่วยให้ผู้ใช้สามารถติดตามปริมาณการดื่มน้ำในแต่ละวันผ่านแอปพลิเคชัน PetPal Health โดยเชื่อมโยงกับการแสดงผลหลอดพลังงานและอารมณ์ของสัตว์เลี้ยง เพื่อสร้างแรงจูงใจในการรักษาสุขภาพ พร้อมระบบป้องกันการกดบันทึกถี่เกินไป (Anti-Spam) และการสรุปผลรายเดือน

## 2. ตารางแสดงสถานะสัตว์เลี้ยงตามปริมาณน้ำ (Pet Status Mapping)
| จำนวนแก้วน้ำ | เปอร์เซ็นต์หลอดพลังงาน | สถานะและอารมณ์ของสัตว์เลี้ยง |
|---|---|---|
| 0 - 3 แก้ว | 0% - 37.5% | เหี่ยวเฉา ป่วย ใกล้ตาย |
| 4 - 6 แก้ว | 50% - 75% | เริ่มเพลีย อ่อนแรง แลบลิ้น |
| 7+ แก้วขึ้นไป | 87.5% - 100%+ | สดชื่น ร่าเริง มีความสุข |

## 3. User stories
| ID | ในฐานะ | ฉันอยาก | เพื่อ |
|---|---|---|---|
| US-1 | เจ้าของสัตว์เลี้ยง | กดบันทึกการดื่มน้ำทีละ 1 แก้ว | ติดตามปริมาณน้ำที่ดื่มในแต่ละวันและเพิ่มพลังงานให้สัตว์เลี้ยง |
| US-2 | เจ้าของสัตว์เลี้ยง | ดูหลอดพลังงานและสถานะของสัตว์เลี้ยงที่เปลี่ยนไปตามจำนวนแก้วน้ำ | ทราบระดับสุขภาพของสัตว์เลี้ยงแบบเรียลไทม์ |
| US-3 | เจ้าของสัตว์เลี้ยง | ดูรายงานสรุปประวัติรายวันและค่าเฉลี่ยการดื่มน้ำต่อเดือน | ประเมินพฤติกรรมการดื่มน้ำในระยะยาว |
| US-4 | เจ้าของสัตว์เลี้ยง | ระบบป้องกันการกดบันทึกซ้ำซ้อน (Anti-Spam) | ป้องกันการกดปุ่มรัวผิดพลาดโดยจำกัดการบันทึก 1 แก้วต่อ 5 นาที |

| AC-4 | US-4 | ก่อน: บันทึกน้ำตอน 10:00 น. และผ่านไป 5 นาที (10:05 น.) / เมื่อ: กดปุ่มบันทึกน้ำ / แล้ว: ระบบอนุญาตให้บันทึกเพิ่มได้สำเร็จ | จำนวนแก้วเพิ่มขึ้น 1 แก้ว และบันทึกเวลาล็อกล่าสุดเป็น 10:05 น. |
| AC-5 | US-5 | ก่อน: เวลา 04:59 น. มีประวัติการดื่มน้ำสะสม 5 แก้ว / เมื่อ: นาฬิกาข้ามไปถึง 05:00 น. ของวันใหม่ / แล้ว: ข้อมูลจำนวนแก้วและหลอดพลังงานถูกรีเซ็ตเป็น 0 (0%) | จำนวนแก้ว = 0, หลอดพลังงาน = 0% บน UI ทันทีเมื่อเปิดแอปหลัง 05:00 น. |
| AC-6 | US-3 | ก่อน: มีประวัติการดื่มน้ำย้อนหลังใน Local Storage / เมื่อ: เปิดหน้า Monthly Report / แล้ว: แสดงกราฟหรือรายการประวัติรายวัน พร้อมค่าเฉลี่ยการดื่มน้ำต่อวันคำนวณถูกต้อง | ค่าเฉลี่ย = (ผลรวมน้ำตลอดเดือน) / (จำนวนวันที่บันทึก) แสดงผลด้วยทศนิยม 1 ตำแหน่ง |

## 5. Edge cases
| ID | สถานการณ์ | ผลที่คาดหวัง |
|---|---|---|
| EC-1 | ผู้ใช้ดื่มน้ำเกินเป้าหมาย (เช่น ดื่มสะสม 12 แก้ว หรือ 150%) | หลอดพลังงานแสดงผลหยุดอยู่ที่ 100% แต่ตัวเลขจำนวนแก้ว (เช่น 12 แก้ว) ยังคงบันทึกและสะสมเพิ่มขึ้นตามจริง |
| EC-2 | อุปกรณ์มือถือหมดแบตเตอรี่หรือปิดเครื่องข้ามคืนในช่วงเวลา 05:00 น. | เมื่อเปิดแอปขึ้นมาใหม่ ระบบตรวจสอบ Timestamp และทำการรีเซ็ตค่าเป็น 0 ทันทีตามเงื่อนไขเวลา 05:00 น. ของวันใหม่ |
| EC-3 | ผู้ใช้พยายามกดรัวปุ่มบันทึกน้ำหลายครั้งติดกันภายในเสี้ยววินาที | ระบบจะบันทึกเพียงครั้งแรกครั้งเดียว และบล็อกการกดที่เหลือตามกฎ Anti-Spam 5 นาที |

## 6. สิ่งที่ไม่ทำในรอบนี้ (Out of scope)
- ไม่มีระบบลดพลังงานน้ำตามเวลาระหว่างวัน (Decay)
- ยังไม่ต่อ Backend หรือ Server ภายนอกเพื่อซิงค์ข้อมูล (ใช้ Local Storage เท่านั้น)
- ยังไม่มีระบบ Social / ดูเพื่อนร่วมกัน
- ยังไม่มีระบบซื้อของแต่งตัวสัตว์เลี้ยงเพิ่มเติม

# Requirements: บันทึกการกินน้ำ (water)

> สถานะ: พร้อมรีวิว · ผู้เขียน: Product agent · ผู้ตรวจ: เพื่อน A · อ้างอิง Issue: #101

## 1. สรุปฟีเจอร์
ฟีเจอร์บันทึกการกินน้ำช่วยให้ผู้ใช้สามารถติดตามปริมาณการดื่มน้ำในแต่ละวันผ่านแอปพลิเคชัน PetPal Health โดยเชื่อมโยงกับการแสดงผลหลอดพลังงานและอารมณ์ของสัตว์เลี้ยง เพื่อสร้างแรงจูงใจในการรักษาสุขภาพ พร้อมระบบป้องกันการกดบันทึกถี่เกินไป (Anti-Spam) และการสรุปผลรายเดือน

## 2. ตารางแสดงสถานะสัตว์เลี้ยงตามปริมาณน้ำ (Pet Status Mapping)
| จำนวนแก้วน้ำ | เปอร์เซ็นต์หลอดพลังงาน | สถานะและอารมณ์ของสัตว์เลี้ยง |
|---|---|---|
| 0 - 3 แก้ว | 0% - 37.5% | เหี่ยวเฉา ป่วย ใกล้ตาย |

| 7+ แก้วขึ้นไป | 87.5% - 100%+ | สดชื่น ร่าเริง มีความสุข |

## 3. ขั้นตอนการใช้งาน (happy path)
1. ผู้ใช้เปิดแอปพลิเคชัน PetPal Health เข้าสู่หน้าจอหลัก (S-1) ระบบตรวจสอบเวลา หากผ่านเวลา 05:00 น. ของวันใหม่ ข้อมูลจำนวนแก้วและพลังงานจะถูกรีเซ็ตเป็น 0 อัตโนมัติ
2. ผู้ใช้เห็นสัตว์เลี้ยงในสถานะปัจจุบันและหลอดพลังงาน
3. ผู้ใช้กดปุ่ม "+" เพื่อบันทึกการดื่มน้ำ
4. ระบบตรวจสอบเงื่อนไข Anti-Spam (ต้องผ่านไปแล้วอย่างน้อย 5 นาทีจากการบันทึกครั้งล่าสุด)
5. เมื่อผ่านเงื่อนไข ระบบบันทึกข้อมูลลง Local Storage จำนวนแก้วเพิ่มขึ้น 1 แก้ว หลอดพลังงานเพิ่มขึ้น 12.5% และอัปเดตสถานะสัตว์เลี้ยงทันที
6. ผู้ใช้ต้องการดูประวัติย้อนหลัง กดปุ่ม "รายงานรายเดือน" เพื่อเข้าสู่หน้าจอ S-2 และดูค่าเฉลี่ยการดื่มน้ำรายเดือน
