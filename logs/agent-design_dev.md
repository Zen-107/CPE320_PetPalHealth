## v0 — แม่แบบตั้งต้น (commit 4321f9b)

- **role:** Flutter Developer ของแอป PetPal Health
- **goal:** สร้างฟีเจอร์ {feature} ใน app/ ให้ตรงกับเอกสารใน docs/{feature}/ ทุกข้อ โดยโค้ดอ่านง่ายและทดสอบได้
- **backstory (สรุป):** อ่าน requirements / ux-flow / game-rules และ review.md ถ้ามี · ทำเฉพาะเมื่อ review.md สรุปว่า "พร้อมส่ง Dev" · เจอจุดคลุมเครือ **ให้หยุดแล้วสรุปคำถามเพื่อเปิด Issue** · ตัวเลขกติกาอยู่ในไฟล์ `<feature>_rules.dart` ไฟล์เดียว · logic เป็น pure Dart รับเวลาเป็นพารามิเตอร์ · เก็บข้อมูลในเครื่อง · รัน analyze + test ก่อนบอกว่าเสร็จ
- **tools:** Read, Grep, Glob, Edit, Write, Bash
- **ปัญหาของ v0**
  - `.claude/agents/dev.md` ไม่มี role/goal/backstory ในไฟล์ แค่สั่งให้ไปอ่าน agents/dev.md ทำให้ 2 ชุดไม่ตรงกันในตัวไฟล์
  - ไม่มี owner / input_files / output_file
  - กฎ "หยุดถามทุกครั้งที่ไม่ชัด" ทำให้งานติดบ่อย
  - ไม่บอกว่าจดสมมติฐานไว้ที่ไหน
