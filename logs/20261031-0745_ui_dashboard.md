## การตัดสินใจหลักพร้อมเหตุผล

1. **ทางเข้า = `IconButton` `dashboard_entry_button` (`Icons.dashboard`) ใน AppBar ของ water ต่อจาก `food_entry_button`** — pattern เดียวกับ steps/food (D-5), ไม่เปลี่ยน home เพราะจะกระทบ signup S-7 และเทสต์ water; ux-flow §3 ข้อ 1 ที่สื่อว่า S-1 เป็นหน้าแรกจดเป็น Q-7
2. **S-1 ใช้ controller ตัวเดียวกับหน้า water** (water + steps/food ที่ inject หรือ owned) และฟังด้วย `Listenable.merge` — ให้ "อัปเดตแบบเรียลไทม์" ตาม ux-flow §2 และข้อมูลตรงกับหน้าฟีเจอร์
3. **ขนาดสัตว์เลี้ยง 200 (ใหม่)** แทน 300 ที่ art แนะนำ — ที่ 300 แถบ 3 หมวดตกจอ 360×640; 200 ทำให้ทั้งหน้าพอดีจอ (≈ 540 dp) และยังเด่นกว่า 160 ของหน้าอื่น
4. **แถบรายหมวด `minHeight: 12` (ใหม่)** — 3 แถบซ้อนกัน ไม่ใช่หลอดหลักของหน้า; ลดความหนาให้ลำดับความสำคัญถูกและพอดีจอ
5. **Total Score Card ใช้ `primaryContainer` (role ใหม่ของแอป)** — แยกตัวเลขหลักออกจากฟองข้อความ `secondaryContainer` โดยไม่ตั้ง hex
6. **ฟองข้อความเหนือหัวสัตว์เลี้ยง 12 px** (brief §3 + pattern Toast ของ food) ไม่ใช่ SnackBar; ช่องจองความสูงด้วยข้อความ Priority 1 ที่มองไม่เห็น (`Visibility(maintainSize)`) — ไม่ล็อกความสูงคงที่ (บทเรียน food D-5) และสัตว์เลี้ยงไม่ขยับตอนข้อความหมุนหรือคิวว่าง; ไม่มี `maxLines` เพราะข้อความต้องครบตรงตัว
7. **แถบอาหารแดง = `colorScheme.error` ผูกกับ `FoodController.isOverLimit`** — เงื่อนไขเดียวกับหลอดแดงของ food (> 100 kcal) และ role สีเดียวกัน
8. **Food ไม่คิดคะแนน → คะแนนรวม = (Steps + Water) / 2, แถบแสดง 「คะแนนอาหาร: ยังไม่มีเป้าหมาย」 (เสนอ)** — ค่าที่ปลอดภัยที่สุด: "ไม่คิดคะแนน" ≠ 0 และไม่ทำให้ผู้ใช้ที่ข้ามโปรไฟล์ไม่มีวันถึง CHEERFUL (Q-1)
9. **ข้อความแจ้งเตือนแสดงไม่รวม `"`** — ถือเป็นตัวคั่น string แบบเดียวกับ 「พอเถอะน้าคนดี」 ของ food (Q-21)
10. **map ท่า:** CRYING → `PetPose.dashboardCrying`, DAZED → `dashboardDazed`, BUBBLY → `dashboardBubbly` (== `waterHappy`), CHEERFUL → `dashboardCheerful`; key `dashboard_pet_image_<mood>` บน `KeyedSubtree` + `GlobalKey(debugLabel: 'dashboard_pet')`; ไม่ใช้ `cheerTrigger`; เทสต์ animate ใช้ `pump(Duration)`
11. **ไม่มีสถานะ disabled / dialog error** — S-1 ไม่มี control; สถานะ "ข้ามช่วงเวลา" = หน้าตาเดียวกับสถานะว่าง หลัง controller ทั้ง 3 ตัดรอบ
