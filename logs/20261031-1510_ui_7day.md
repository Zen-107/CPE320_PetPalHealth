## การตัดสินใจหลักพร้อมเหตุผล (ของ UI — ชั่วคราว)

1. ทางเข้า = `IconButton` ที่ 5 `seven_day_entry_button` (`Icons.history`, tooltip 「ประวัติ 7 วัน」 จาก ux-flow §3 ข้อ 1) ก่อน `water_monthly_report_button` — 5 × 48 = 240 dp ไม่ล้นที่ 360 dp; IconButton ไม่ขยายตาม textScaler; title ตัด ellipsis ตาม default · เสนอทางเลือก dashboard / PopupMenu ไว้ใน Q-1
2. S-1 รับ 3 controller ตัวเดียวกับ dashboard; ตรวจรอบวันทุก 1 วินาที + resume แบบ DashboardController — reuse pattern ที่ผ่าน QA แล้ว
3. Token: SUMMARY = `primaryContainer` (แบบ `dashboard_total_score_card`), การ์ดรายวัน = `Card` default (แบบ `steps_report_summary_card`), ป้าย = `errorContainer` (แบบ `food_full_badge`), ข้อความรอง = `onSurfaceVariant` — ไม่มี hex ใหม่
4. Token ใหม่ 3 ค่า: ป้าย padding 8/4 + `labelLarge` (3 ป้ายต้องพอดีแถวที่ 360 dp), ไอคอน EMPTY 48 (แทนภาพประกอบ), ระยะบรรทัด coaching 4 · padding หน้า 16 (pattern หน้ารายงาน)
5. PNG 4 ไฟล์ใน ux-flow §5 ไม่มีใน repo และ `assets/images/7day/` ไม่ได้ลงทะเบียน → ใช้ colorScheme + Material Icons แทน (Q-6)
6. `SingleChildScrollView` + `Column` ไม่ใช้ `ListView.builder` — การ์ดทั้ง 7 อยู่ใน tree (เทสต์หา Day −6 ได้) · ไม่มี maxLines / ไม่ล็อกความสูง (บทเรียน food D-5 / dashboard D-16)
7. EMPTY ซ่อน SUMMARY_CARD (ข้อความว่างขึ้นที่เดียว) แต่ยังแสดง 7 การ์ด 「ไม่มีข้อมูล」 เพื่อคง AC-1
8. "วันที่มีบันทึก" = หมวดใด > 0; ตัวหารค่าเฉลี่ยรายหมวด = วันที่หมวดนั้น > 0 — สอดคล้องรายงานรายเดือน water / steps
9. เกณฑ์ < 8.0 / < 8000.0 เทียบค่าที่ปัด 1 ตำแหน่งแล้ว (กันข้อความ "เฉลี่ย 8.0 แก้ว น้อยไป")
10. Color Highlighting เขียว/ส้ม/แดงของ brief ไม่ทำรอบนี้ (ไม่มีใน ux-flow/game-rules และต้อง hex ใหม่)
11. ข้ามรอบ 05:00 → การ์ดทั้งชุดกลับค่าเริ่มต้นผ่าน `KeyedSubtree` key ตามวันที่ Day 0
