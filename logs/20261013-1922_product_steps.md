# Brief: ฟีเจอร์นับก้าวและการตั้งเป้าหมายประจำวัน (Step Tracking & Daily Goal)

## 1. ภาพรวมฟีเจอร์ (Overview)
ระบบนับก้าวเดินอัตโนมัติ (Passive Tracking) ตัดรอบสถิติทุกวันเวลา 05:00 น. นำก้าวเดินสะสมคำนวณ % พลังงานเพื่อขับเคลื่อนรูปร่างสัตว์เลี้ยงเสมือนจริงในแอป PetPal Health และส่งออกรายงานสรุปประจำเดือนเป็นภาพ PNG

## 2. การตั้งและปรับเปลี่ยนเป้าหมาย (Goal Setting & Logic)
- **ค่าเป้าหมายเริ่มต้นที่เลือกไว้ล่วงหน้า (Pre-selected / Default Goal):** **8,000 ก้าว** (กำหนดค่าเริ่มต้น `DEFAULT_DAILY_GOAL = 8,000 ก้าว` ไว้ให้อัตโนมัติในระบบสำหรับผู้ใช้เปิดแอปครั้งแรก)
- **กลุ่มตัวเลือกเป้าหมาย (Goal Options):** ต้องมีให้เลือกครบทั้ง 3 กลุ่ม:
  - กลุ่มทั่วไป: 6,000 / 7,000 / 8,000 ก้าว
  - กลุ่มควบคุมน้ำหนัก: 9,000 / 10,000 / 11,000 / 12,000 ก้าว
  - กลุ่มนักกีฬา: 13,000 / 14,000 / 15,000 ก้าว
- **เงื่อนไขการปรับเป้าหมาย:** ปรับเปลี่ยนได้มากที่สุด **1 ครั้งต่อวัน** (รีเซ็ตโควต้าตอน 05:00 น.)
  - เปลี่ยนก่อน 05:00 น. ➔ มีผลรอบวันปัจจุบันทันที
  - เปลี่ยนหลัง 05:00 น. ➔ มีผลรอบวันถัดไป
  - เกินโควต้า ➔ ปุ่ม Disabled (สีเทาจาง) + แสดง Toast Message *"คุณสามารถปรับเปลี่ยนเป้าหมายได้เพียง 1 ครั้งต่อวัน"*
- **การตัดรอบสถิติ:** รีเซ็ตสถิติก้าวเดินและหลอดพลังงานทุกวันเวลา **05:00 น.**

## 3. ระบบพลังงานและการเปลี่ยนรูปร่างสัตว์เลี้ยง (Pet Visual System)
- คำนวณ % พลังงาน: `(ก้าวเดินจริง / เป้าหมาย) * 100` (สูงสุด 100%)
- **Pet Status Mapping & Code Enum:**
  - `< 35%`: "อ้วนอืด" (Enum: `FAT`)
  - `35% - 69.99%`: "จ่ำม่ำ" (Enum: `CHUBBY`)
  - `70% - 99.99%`: "หุ่นลีน (สมส่วน)" (Enum: `LEAN`)
  - `>= 100%`: "มีกล้ามขา" (Enum: `MUSCLE`)

## 4. เงื่อนไขทางเทคนิคและการขอสิทธิ์ (Permissions & App Logic)
- ขอสิทธิ์ Activity Recognition เมื่อเปิดแอปครั้งแรก
- อัปเดตข้อมูลก้าวเดินและหลอดพลังงานทันทีเมื่อเปิดแอปหรือสลับมา Foreground

## 5. ตารางสถานการณ์ Edge Cases (EC-1 ถึง EC-6)
1. **Permission Denied (EC-1):** ล็อกฟังก์ชัน แสดง Popup + ปุ่ม Shortcut ไปหน้า Settings
2. **Battery Drain / Device Shutdown (EC-2):** ดึงข้อมูลก้าวล่าสุดจาก Local Storage เมื่อเปิดแอปใหม่
3. **Timezone / Clock Modification (EC-3):** ยึดเวลาตาม Server Time ป้องกันการปรับเวลารีเซ็ตสถิติ
4. **Multi-device Sync (EC-4):** Sync เป้าหมายล่าสุดและดึงสถิติก้าวเฉพาะของวันนั้น ไม่นับซ้ำ
5. **Foreground Crossing (EC-5):** เปิดแอปค้างข้าม 05:00 น. ให้ตัดรอบสถิติและรีเซ็ตอัตโนมัติทันที
6. **No Hardware Step Counter (EC-6):** หากไม่มีเซนเซอร์ฮาร์ดแวร์ แสดง Popup และล็อกฟังก์ชัน (แนวเดียวกับ EC-1)

## 6. รายงานสรุปผลรายเดือน (Monthly Health Report System)

- **Out of Scope:** Push Notification แจ้งเตือน 80%, In-App Dashboard กราฟแนวโน้ม, Leaderboard, Smartwatch Sync

| ID | อ้างถึง | เงื่อนไข (ก่อน / เมื่อ / แล้ว) | ค่าที่ทดสอบได้ |
|---|---|---|---|
| AC-1 | US-1 | ก่อน: ผู้ใช้เปิดแอป PetPal Health ครั้งแรก / เมื่อ: ระบบโหลดหน้าฟีเจอร์ Steps / แล้ว: ระบบแสดงค่าเป้าหมาย (กำหนดค่าเริ่มต้น DEFAULT_DAILY_GOAL = 8,000 ก้าว) ทันทีอัตโนมัติ | ค่าเริ่มต้นของเป้าหมายเท่ากับ 8,000 ก้าว |
| AC-2 | US-2 | ก่อน: อยู่ในหน้าตั้งค่าเป้าหมาย / เมื่อ: ผู้ใช้เลือกตัวเลือกในกลุ่มทั่วไป (6,000/7,000/8,000) กลุ่มควบคุมน้ำหนัก (9,000/10,000/11,000/12,000) หรือกลุ่มนักกีฬา (13,000/14,000/15,000) / แล้ว: ระบบบันทึกเป้าหมายใหม่ตามกลุ่มที่เลือก | เป้าหมายอัปเดตตรงตามปุ่มที่ผู้ใช้กดเลือก |
| AC-3 | US-3 | ก่อน: ผู้ใช้เปลี่ยนเป้าหมายสำเร็จไปแล้ว 1 ครั้งในรอบวัน / เมื่อ: ผู้ใช้พยายามกดเปลี่ยนเป้าหมายครั้งที่ 2 / แล้ว: ปุ่มถูก Disabled (สีเทาจาง) และแสดง Toast Message ว่า "คุณสามารถปรับเปลี่ยนเป้าหมายได้เพียง 1 ครั้งต่อวัน" | ปุ่มถูกปิดการใช้งานและมี Toast แสดงขึ้นมาจริง |
| AC-4 | US-4 | ก่อน: สัตว์เลี้ยงมีก้าวเดิน 0 ก้าว (0%) / เมื่อ: ก้าวเดินถึง 3,500 ก้าว (35.00%) / แล้ว: รูปร่างสัตว์เลี้ยงเปลี่ยนจากสถานะ "อ้วนอืด" เป็น "จ่ำม่ำ" (Enum: CHUBBY) | เปอร์เซ็นต์ >= 35% สถานะเปลี่ยนเป็น CHUBBY |
| AC-5 | US-5 | ก่อน: อยู่ในหน้าสรุปผลรายเดือน / เมื่อ: ผู้ใช้กดปุ่ม Export Report / แล้ว: ระบบสร้างไฟล์ภาพ PNG สรุปข้อมูลการเดินและน้ำรวม 1 หน้าถ้วนสำเร็จ | ได้ไฟล์ภาพ PNG ขนาด 1 หน้าจอที่มีข้อมูลครบถ้วน |

## 5. Edge cases

| ID | สถานการณ์ | ผลที่คาดหวัง |
|---|---|---|
| EC-1 | **Permission Denied:** ผู้ใช้ปฏิเสธการขอสิทธิ์ Activity Recognition | ล็อกฟังก์ชันนับก้าว แสดง Popup แจ้งเตือน พร้อมปุ่ม Shortcut พาผู้ใช้ไปหน้า Settings ของมือถือ |
| EC-2 | **Battery Drain / Device Shutdown:** มือถือแบตหมดหรือเครื่องดับระหว่างวัน | ดึงข้อมูลก้าวเดินล่าสุดจาก Local Storage มาแสดงทันทีเมื่อเปิดแอปใหม่ ข้อมูลไม่หาย |
| EC-3 | **Timezone / Clock Modification:** ผู้ใช้เปลี่ยนเวลานาฬิกาในเครื่องเพื่อหลอกการตัดรอบสถิติ | ระบบยึดเวลาตาม Server Time ในการตัดรอบสถิติและรีเซ็ตค่าตอน 05:00 น. เสมอ |
| EC-4 | **Multi-device Sync:** ผู้ใช้ล็อกอินบัญชีเดียวกันบนมือถือ 2 เครื่อง | Sync เป้าหมายล่าสุดและดึงสถิติก้าวเฉพาะของวันนั้นเข้าสู่ Server โดยไม่นำก้าวมาบวกซ้ำกัน |
| EC-5 | **Foreground Crossing:** ผู้ใช้เปิดแอปค้างไว้ข้ามเวลา 05:00 น. | ระบบทำการตัดรอบสถิติและรีเซ็ตหลอดพลังงานเป็น 0 ทันทีโดยไม่ต้องปิดเปิดแอปใหม่ |
| EC-6 | **No Hardware Step Counter:** มือถือรุ่นเก่าไม่มีเซนเซอร์ฮาร์ดแวร์นับก้าว | แสดง Popup แจ้งเตือนข้อจำกัดฮาร์ดแวร์ และล็อกฟังก์ชันนับก้าว (แนวเดียวกับ EC-1) |

## 6. สิ่งที่ไม่ทำในรอบนี้ (Out of scope)
- Push Notification แจ้งเตือนเมื่อสัตว์เลี้ยงเดินครบ 80% ของเป้าหมาย
- In-App Dashboard แสดงกราฟแนวโน้มสถิติรายสัปดาห์/รายปี
