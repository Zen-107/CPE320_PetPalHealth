ฟีเจอร์นี้ช่วยให้เจ้าของสัตว์เลี้ยงบันทึกปริมาณการดื่มน้ำในชีวิตประจำวันเพื่อส่งเสริมสุขภาพ พร้อมเชื่อมโยงกับหลอดพลังงานและสถานะอารมณ์ของสัตว์เลี้ยงในแอป PetPal Health เพื่อกระตุ้นพฤติกรรมสุขภาพที่ดีผ่านการพัฒนาด้วย Flutter และ Local Storage

## 2. User stories

| ID | ในฐานะ | ฉันอยาก | เพื่อ |
|---|---|---|---|
| US-1 | เจ้าของสัตว์เลี้ยง | กดบันทึกปริมาณการดื่มน้ำได้ครั้งละ 1 แก้ว (12.5%) | เพิ่มพลังงานสะสมและดูแลสุขภาพสัตว์เลี้ยง |
| US-2 | เจ้าของสัตว์เลี้ยง | เห็นสถานะอารมณ์ของสัตว์เลี้ยงเปลี่ยนไปตามระดับพลังงานน้ำ | ทราบผลลัพธ์และระดับสุขภาพของสัตว์เลี้ยงได้อย่างชัดเจน |
| US-3 | เจ้าของสัตว์เลี้ยง | ระบบป้องกันการสแปมการกดบันทึกน้ำ | ป้องกันการกดรัวและรักษาความถูกต้องของข้อมูล |
| US-4 | เจ้าของสัตว์เลี้ยง | ระบบรีเซ็ตข้อมูลและหลอดพลังงานเป็น 0 ตอน 05:00 น. ของทุกวัน | เริ่มต้นวันใหม่ด้วยเป้าหมายการดื่มน้ำที่สด 0% เสมอ |

## 3. Acceptance criteria

| ID | อ้างถึง | เงื่อนไข (ก่อน /เมื่อ / แล้ว) | ค่าที่ทดสอบได้ |
|---|---|---|---|
| AC-1 | US-1 | ก่อน: หลอดพลังงานอยู่ที่ 0% (0 แก้ว)<br>เมื่อ: ผู้ใช้กดปุ่มบันทึกน้ำ 1 ครั้ง<br>แล้ว: หลอดพลังงานเพิ่มขึ้นเป็น 12.5% และจำนวนแก้วแสดงผลเป็น 1 แก้ว | พลังงาน = 12.5%, จำนวนแก้ว = 1 |
| AC-2 | US-2 | ก่อน: หลอดพลังงานอยู่ที่ 25% (2 แก้ว)<br>เมื่อ: ผู้ใช้เปิดหน้าจอหลัก<br>แล้ว: สัตว์เลี้ยงแสดงสถานะและอารมณ์ "เหี่ยวเฉา ป่วย ใกล้ตาย" | ช่วงพลังงาน 0% - 29% (0 - 2 แก้ว) |
| AC-3 | US-2 | ก่อน: หลอดพลังงานอยู่ที่ 37.5% (3 แก้ว)<br>เมื่อ: ผู้ใช้เปิดหน้าจอหลัก<br>แล้ว: สัตว์เลี้ยงแสดงสถานะและอารมณ์ "เริ่มเพลีย อ่อนแรง แลบลิ้น" | ช่วงพลังงาน 30% - 59% (3 - 4 แก้ว) |
| AC-4 | US-2 | ก่อน: หลอดพลังงานอยู่ที่ 62.5% (5 แก้ว)<br>เมื่อ: ผู้ใช้เปิดหน้าจอหลัก<br>แล้ว: สัตว์เลี้ยงแสดงสถานะและอารมณ์ "สดชื่น ร่าเริง มีความสุข" | ช่วงพลังงาน 60% - 100% (5 - 8+ แก้ว) |
| AC-5 | US-3 | ก่อน: ผู้ใช้กดบันทึกน้ำครั้งที่ 1 สำเร็จ<br>เมื่อ: ผู้ใช้กดบันทึกน้ำครั้งที่ 2 ภายในเวลา 4 นาที 59 วินาที<br>แล้ว: ระบบแสดงข้อความแจ้งเตือนคูลดาวน์ และไม่อนุญาตให้เพิ่มจำนวนแก้ว | แสดง Toast/Error และไม่อนุญาตให้บันทึกซ้ำภายใน 5 นาที |
| AC-6 | US-4 | ก่อน: หลอดพลังงานอยู่ที่ 100% (8 แก้ว) และเวลาเครื่องจำลองเป็น 04:59 น.<br>เมื่อ: เวลาเครื่องเปลี่ยนเป็น 05:00 น.<br>แล้ว: หลอดพลังงานถูกรีเซ็ตเป็น 0% และจำนวนแก้วแสดงผลเป็น 0 แก้วทันที | พลังงาน = 0%, จำนวนแก้ว = 0 เวลา 05:00 น. |

## 4. Edge cases

| ID | สถานการณ์ | ผลที่คาดหวัง |
|---|---|---|
| EC-1 | ผู้ใช้พยายามกดบันทึกน้ำต่อเนื่องจนครบ 8 แก้ว (100%) แล้วกดเพิ่มอีกครั้งในวันเดียวกัน | หลอดพลังงานหยุดสะสมสูงสุดที่ 100% (แสดงผล 8+ แก้ว) และไม่เกิน 100% |
| EC-2 | แอปถูกปิดและเปิดใหม1ในระหว่างวัน (เช่น ตอนบ่าย 2) | ข้อมูลจำนวนแก้ว เวลาบันทึกครั้งล่าสุด และหลอดพลังงานปัจจุบันยังคงเดิมไม่สูญหาย (ดึงค่าจาก Local Storage) |
| EC-3 | นาฬิกาของเครื่องถูกปรับเปลี่ยนเวลาถอยหลังข้ามผ่านช่วง 05:00 น. | ระบบตรวจสอบเวลาล็อกล่าสุดและทำการรีเซ็ตข้อมูลเป็น 0 ทันทีหากตรวจพบการข้ามวัน |

## 5. สิ่งที่ไม่ทำในรอบนี้ (Out of scope)
- ไม่มีระบบลดพลังงานน้ำตามเวลาระหว่างวัน (Decay)
- ยังไม่ต่อ Backend หรือ Server ภายนอก (เก็บบนเครื่องทั้งหมด)
- ยังไม่มีระบบ Social / ดูเพื่อนร่วมกัน
- ยังไม่มีระบบซื้อของแต่งตัวสัตว์เลี้ยงเพิ่มเติม

## 6. ข้อมูลที่ใช้ (ข้อมูลสมมติเท่านั้น)

| ข้อมูล | ชนิด/หน่วย | เก็บที่ไหน |
|---|---|---|
| current_water_cups | Integer (จำนวนแก้ว) | Local Storage (SharedPreferences / Hive) |
| water_energy_percentage | Float (เปอร์เซ็นต์ %) | Local Storage (SharedPreferences / Hive) |
| last_logged_timestamp | DateTime (ISO 8601) | Local Storage (SharedPreferences / Hive) |
| last_reset_date | String (YYYY-MM-DD) | Local Storage (SharedPreferences / Hive) |

## 7. คำถามที่ยังเปิดอยู่
- หากผู้ใช้เปลี่ยน Timezone ของเครื่อง จะส่งผลต่อการรีเซ็ตตอน 05:00 น. หรือไม่ และควรใช้เวลาตามเครื่อง (Local Time) หรือเวลามาตรฐาน (UTC) ในการเทียบเวลา 05:00 น.
