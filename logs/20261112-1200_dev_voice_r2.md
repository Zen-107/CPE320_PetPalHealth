## สมมติฐาน (ASSUMPTION / DECIDED ในคอมเมนต์)

1. `network_required` ต้องเท่ากับ `"0"` เท่านั้น — ไม่มีคีย์หรือเป็นค่าอื่น = ไม่เลือก (ถ้าไม่แน่ใจให้ถือว่าใช้เน็ตไว้ก่อน)
2. ข้าม voice ที่ `features` มี `notInstalled` (ยังไม่ได้ดาวน์โหลด) — กันไว้อีกชั้นนอกเหนือจาก `isLanguageInstalled`
3. locale ไทย = `th` / `th-…` / `th_…` ไม่สนตัวพิมพ์ (`thx-XX` ไม่นับ) · มีหลายตัวให้เลือกตัวที่ตรง `th-TH` ก่อน ไม่มีก็เอาตัวแรก
4. `setVoice` คืนค่าอื่นที่ไม่ใช่ `1` = ไม่สำเร็จ → `prepare()` คืน false
5. เรียก `setLanguage` ก่อน แล้ว `setVoice` ทับ เพราะ engine อาจเลือก voice เริ่มต้นของภาษาซึ่งอาจเป็น server voice
6. ข้อมูล list/map ที่ผิดรูปแบบถูกข้าม ไม่ throw
