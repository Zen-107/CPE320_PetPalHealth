# Requirements: การบันทึกการกินน้ำ (water)

> สถานะ: พร้อมรีวิว · ผู้เขียน: Product agent · ผู้ตรวจ: เพื่อน A · อ้างอิง Issue: #101

## 1. สรุปฟีเจอร์
ฟีเจอร์บันทึกการกินน้ำช่วยให้ผู้ใช้ติดตามปริมาณน้ำดื่มประจำวันได้ง่าย พร้อมเชื่อมโยงพฤติกรรมกับหลอดพลังงานและอารมณ์ของสัตว์เลี้ยงในแอป PetPal Health โดยระบบจะบันทึกข้อมูลสะสมและรีเซ็ตทุกตี 5 พร้อมระบบป้องกันการกดรัว (Anti-Spam)

## 2. User stories

| ID | ในฐานะ | ฉันอยาก | เพื่อ |
|---|---|---|---|
| US-1 | ผู้ใช้งานแอป | กดบันทึกปริมาณการดื่มน้ำทีละแก้ว | เพิ่มพลังงานสะสมและดูแลสัตว์เลี้ยงของฉัน |
| US-2 | ผู้ใช้งานแอป | ดูสถานะและอารมณ์ของสัตว์เลี้ยงที่เปลี่ยนไปตามปริมาณน้ำที่ดื่ม | รู้สึกสนุกและมีแรงจูงใจในการดื่มน้ำ |
| US-3 | ผู้ใช้งานแอป | ดูรายงานสรุปประวัติรายวันและค่าเฉลี่ยการดื่มน้ำ | ติดตามพฤติกรรมการดื่มน้ำของตนเองในระยะยาว |

## 3. Acceptance criteria

| ID | อ้างถึง | เงื่อนไข (ก่อน / เมื่อ / แล้ว) | ค่าที่ทดสอบได้ |
|---|---|---|---|
| AC-1 | US-1 | ก่อน: น้ำ 0 แก้ว (พลังงาน 0%) / เมื่อ: ผู้ใช้กดปุ่มบันทึกน้ำ 1 ครั้ง / แล้ว: หลอดพลังงานเพิ่มขึ้น 12.5% และจำนวนแก้วเพิ่มเป็น 1 แก้ว | จำนวนแก้ว = 1, พลังงาน = 12.5% |
| AC-2 | US-2 | ก่อน: น้ำ 0 แก้ว (0%) / เมื่อ: ดื่มน้ำสะสม 0 - 2 แก้ว (0% - 29%) / แล้ว: สัตว์เลี้ยงแสดงสถานะ "เหี่ยวเฉา ป่วย ใกล้ตาย" | ช่วงพลังงาน 0% - 29% (0 - 2 แก้ว) |
| AC-3 | US-2 | ก่อน: น้ำ 2 แก้ว / เมื่อ: ดื่มน้ำสะสมถึง 3 - 4 แก้ว (30% - 59%) / แล้ว: สัตว์เลี้ยงเปลี่ยนสถานะเป็น "เริ่มเพลีย อ่อนแรง แลบลิ้น" | ช่วงพลังงาน 30% - 59% (3 - 4 แก้ว) |
| AC-4 | US-2 | ก่อน: น้ำ 4 แก้ว / เมื่อ: ดื่มน้ำสะสมตั้งแต่ 5 แก้วขึ้นไป (60% - 100%) / แล้ว: สัตว์เลี้ยงเปลี่ยนสถานะเป็น "สดชื่น ร่าเริง มีความสุข" และแสดงผลพลังงานสูงสุดที่ 100% แม้จะดื่มเกิน 8 แก้ว | ช่วงพลังงาน 60% - 100%+ (5 - 8+ แก้ว) |
| AC-5 | US-1 | ก่อน: บันทึกน้ำครั้งที่ 2 สำเร็จ / เมื่อ: ผู้ใช้พยายามกดบันทึกครั้งที่ 3 ภายในช่วงเวลา 5 นาที / แล้ว: ระบบแสดง Toast แจ้งเตือน Anti-Spam และไม่บันทึกข้อมูลเพิ่ม | สูงสุด 2 คลิกต่อ 5 นาที, แสดง Toast เตือน |
| AC-6 | US-1 | ก่อน: ดื่มน้ำไปแล้ว 6 แก้ว (พลังงาน 75%) และเวลาถึง 04:59 น. / เมื่อ: นาฬิกาเข้าสู่เวลา 05:00 น. ของวันใหม่ / แล้ว: จำนวนแก้วและหลอดพลังงานถูกรีเซ็ตเป็น 0 ทันที | จำนวนแก้ว = 0, พลังงาน = 0%, เวลา 05:00 น. |

## 4. Edge cases

| ID | สถานการณ์ | ผลที่คาดหวัง |

| EC-2 | ผู้ใช้พยายามเปลี่ยนเวลาในเครื่องโทรศัพท์ย้อนไปมาเพื่อหลีกเลี่ยงการรีเซ็ต 05:00 น. | ระบบอ้างอิงเวลาจริงของอุปกรณ์ หรือรีเซ็ตเมื่อตรวจพบการข้ามรอบวัน (ขึ้นอยู่กับการทำงานของ Local Storage) |

## 5. สิ่งที่ไม่ทำในรอบนี้ (Out of scope)
- ไม่มีระบบลดพลังงานน้ำตามเวลาระหว่างวัน (Decay)
- ยังไม่ต่อ Backend หรือ Server ภายนอกเพื่อซิงค์ข้อมูล
- ยังไม่มีระบบ Social / ดูเพื่อนร่วมกัน
- ยังไม่มีระบบซื้อของแต่งตัวสัตว์เลี้ยงเพิ่มเติม

## 6. ข้อมูลที่ใช้ (ข้อมูลสมมติเท่านั้น)

| water_energy | Float (%) | Local Storage (SharedPreferences / Hive) |
| last_logged_timestamp | Timestamp (เวลาที่กดล่าสุด) | Local Storage (SharedPreferences / Hive) |
