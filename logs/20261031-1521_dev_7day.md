## สมมติฐานทั้งหมด (ASSUMPTION)

1. Day 0 = วันล่าสุดใน `state.day` ของ steps / food (fallback `WaterLogic.logicalDay(now)`) — ui-spec ไม่บอกว่ายึดนาฬิกาตัวไหน; ทางนี้ทำให้ Day 0 ตรงกับ "วันนี้" ของ controller เดิมเสมอ ไม่ย้อนตามนาฬิกาที่ถอยหลัง และไม่มีนาฬิกาแยกที่อาจไม่ตรงกับ controller (`seven_day_logic.dart` `currentDay`)
2. ค่าของวันที่ตรงกับ `state.day` ของ steps / food ใช้ค่าปัจจุบัน (`steps` / `totalCalories` / meals / `FoodController.isOverLimit`) วันอื่นใช้ `history` — ขยายจาก ui-spec §2.2 ให้ครอบคลุมช่วงสั้น ๆ ที่ controller ตัวหนึ่ง rollover ก่อนอีกตัว
3. ค่าติดลบจากข้อมูลเสีย → 0 (ป้องกันไว้ ไม่ควรเกิด)
4. `dayCheckIntervalSeconds` = 1 (ui-spec §1.3)
5. `emptyIconSize` = 48 + `Icons.inbox_outlined`, ไอคอนลูกศร default ของ ExpansionTile, พื้น SUMMARY = `primaryContainer` แทน PNG 4 ไฟล์ (Q-6)
6. Q-2: "วันที่มีบันทึก" = หมวดใด > 0; ตัวหารรายหมวด = วันที่หมวดนั้น > 0; ค่า 0 = ไม่มีบันทึก
