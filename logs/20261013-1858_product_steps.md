# Brief: ฟีเจอร์นับก้าวและการตั้งเป้าหมายประจำวัน (Step Tracking & Daily Goal)

## 1. ภาพรวมฟีเจอร์ (Overview)
ระบบจับการเคลื่อนไหวเพื่อบันทึกก้าวเดินประจำวันของผู้ใช้แบบอัตโนมัติ (Passive Tracking) โดยมีการตัดรอบสถิติประจำวันในเวลา 05:00 น. ของทุกวัน และนำก้าวเดินสะสมมาคำนวณเทียบกับเป้าหมายเป็นพลังงาน (% Goal) เพื่อขับเคลื่อนรูปร่างและสถานะของสัตว์เลี้ยงเสมือนจริงในแอป PetPal Health พร้อมระบบส่งออกรายงานสรุปผลรายเดือนเป็นภาพ PNG

## 2. การตั้งและปรับเปลี่ยนเป้าหมาย (Goal Setting & Logic)
- **ค่าเริ่มต้นระบบ (Default System Goal):** **8,000 ก้าว** (เมื่อเปิดใช้งานครั้งแรก ระบบจะกำหนดค่านี้เป็นเป้าหมายเริ่มต้นให้อัตโนมัติ โดยผู้ใช้สามารถเลือกปรับเปลี่ยนเป็นเป้าหมายอื่นได้ตลอดเวลา)
- **ตัวเลือกเป้าหมายในระบบ (Goal Options):** ต้องระบุตัวเลือกทั้ง 3 กลุ่มนี้ในเอกสาร Requirements อย่างชัดเจน ห้ามละเว้น ได้แก่

  - กลุ่มควบคุมน้ำหนัก: 9,000 / 10,000 / 11,000 / 12,000 ก้าว
  - กลุ่มนักกีฬา: 13,000 / 14,000 / 15,000 ก้าว
- **เงื่อนไขการปรับเป้าหมาย (Goal Change Rules):**
  - **โควต้าการปรับเป้าหมาย:** สามารถกดปรับเปลี่ยนเป้าหมายได้มากที่สุด **วันละ 1 ครั้ง** (โควต้ารีเซ็ตทุก 05:00 น.)
  - **ช่วงเวลาที่มีผล:**
    - หากปรับเปลี่ยนเป้าหมายก่อนเวลา 05:00 น. ➔ มีผลกับรอบวันปัจจุบันทันที
    - หากปรับเปลี่ยนเป้าหมายหลังเวลา 05:00 น. ➔ มีผลในรอบวันถัดไป (เริ่มนับจาก 05:00 น.)
  - **กรณีใช้โควต้าเกิน 1 ครั้ง/วัน:** ปุ่มปรับเป้าหมายต้องถูก Disabled (สีเทาจาง) และแสดง Toast Message เตือนว่า *"คุณสามารถปรับเปลี่ยนเป้าหมายได้เพียง 1 ครั้งต่อวัน"*
  - หากผู้ใช้ไม่ได้กดปรับเปลี่ยน ให้ใช้ค่าเป้าหมายล่าสุดที่เคยเลือกไว้ (หรือค่า Default 8,000 ก้าว)
- **การตัดรอบสถิติประจำวัน:** ข้อมูลนับก้าวและพลังงานทั้งหมดจะถูกรีเซ็ตและตัดรอบใหม่ในเวลา **05:00 น. ของทุกวัน** (รอบวันนับช่วง 05:00 - 04:59 น.)

- **การแสดงผลรูปร่างสัตว์เลี้ยงตาม % การเดิน (Pet Status Mapping & Code Enum):**
  - **น้อยกว่า 35%:** แสดงผล "อ้วนอืด" (Enum Key: `FAT`)
  - **35% - 69.99%:** แสดงผล "จ่ำม่ำ" (Enum Key: `CHUBBY`)

  - **ครบ 100% ขึ้นไป:** แสดงผล "มีกล้ามขา" (Enum Key: `MUSCLE`)

## 4. เงื่อนไขทางเทคนิคและการขอสิทธิ์ (Permissions & App Logic)
- **การขอสิทธิ์ (Permission Request):** ขอสิทธิ์เข้าถึงเซนเซอร์นับก้าว (Activity Recognition / Motion & Fitness) เมื่อผู้ใช้เปิดใช้งานครั้งแรก
- **การอัปเดตข้อมูล (Data Refresh):** คำนวณและอัปเดตจำนวนก้าวและเปอร์เซ็นต์หลอดพลังงานทุกครั้งที่เปิดแอป (On App Launch / Resume to Foreground)

## 5. ตารางสถานการณ์ Edge Cases (Must Include 6 Edge Cases)
1. **การปฏิเสธสิทธิ์ (Permission Denied - EC-1):** หากผู้ใช้กดปฏิเสธสิทธิ์ ระบบจะทำการล็อกฟังก์ชันนับก้าวทั้งหมด พร้อมแสดง Pop-up แจ้งเตือนและมีปุ่ม Shortcut พาผู้ใช้ไปหน้า Settings ของเครื่องเพื่อเปิดสิทธิ์
2. **กรณีแบตเตอรี่หมด/ปิดเครื่อง (Battery Drain / Device Shutdown - EC-2):** หากแบตเตอรี่หมดหรือเครื่องดับระหว่างวัน ระบบจะดึงข้อมูลก้าวล่าสุดที่มีการบันทึกไว้ใน Local Storage มาแสดงผลโดยอัตโนมัติทันทีเมื่อเปิดแอปครั้งถัดไป
3. **การเปลี่ยน Timezone หรือเวลาในเครื่อง (Timezone / Clock Modification - EC-3):** หากผู้ใช้เปลี่ยน Timezone หรือปรับเวลาในเครื่องย้อนหลัง ระบบยึดเวลาตาม Network/Server Time เท่านั้น ป้องกันการปรับเวลารีเซ็ตสถิติย้อนหลัง
4. **การสลับอุปกรณ์ (Multi-device Sync - EC-4):** หากผู้ใช้สลับไปใช้อุปกรณ์เครื่องใหม่ระหว่างวัน ระบบจะทำการ Sync เป้าหมายล่าสุดและดึงสถิติก้าวเดินสะสมเฉพาะของวันนั้นมาแสดงผลโดยไม่นับก้าวซ้ำซ้อน
5. **การเปิดแอปค้างไว้ข้ามช่วงเวลา 05:00 น. (Foreground Crossing - EC-5):** หากผู้ใช้เปิดหน้าจอแอปค้างไว้จนถึงเวลา 05:00 น. ระบบต้องทำการตัดรอบสถิติ รีเซ็ตหลอดพลังงานและจำนวนก้าวเป็น 0 และเริ่มรอบวันใหม่อัตโนมัติทันทีโดยไม่ต้อง Restart แอป
6. **กรณีอุปกรณ์ไม่มีฮาร์ดแวร์เซนเซอร์นับก้าว (No Hardware Step Counter - EC-6):** หากอุปกรณ์ของผู้ใช้ไม่มีเซนเซอร์ฮาร์ดแวร์นับก้าว ระบบจะแสดง Pop-up แจ้งเตือนข้อจำกัดของอุปกรณ์ และทำการล็อกฟังก์ชันนับก้าวทั้งหมด (แนวทางเดียวกับ EC-1)

## 6. รายงานสรุปผลรายเดือน (Monthly Health Report System)

# Brief: ฟีเจอร์นับก้าวและการตั้งเป้าหมายประจำวัน (Step Tracking & Daily Goal)

## 1. ภาพรวมฟีเจอร์ (Overview)
ระบบจับการเคลื่อนไหวเพื่อบันทึกก้าวเดินประจำวันของผู้ใช้แบบอัตโนมัติ (Passive Tracking) โดยมีการตัดรอบสถิติประจำวันในเวลา 05:00 น. ของทุกวัน และนำก้าวเดินสะสมมาคำนวณเทียบกับเป้าหมายเป็นพลังงาน (% Goal) เพื่อขับเคลื่อนรูปร่างและสถานะของสัตว์เลี้ยงเสมือนจริงในแอป PetPal Health พร้อมระบบส่งออกรายงานสรุปผลรายเดือนเป็นภาพ PNG

## 2. การตั้งและปรับเปลี่ยนเป้าหมาย (Goal Setting & Logic)
- **ค่าเริ่มต้นระบบ (Default System Goal):** **8,000 ก้าว** (เมื่อเปิดใช้งานครั้งแรก ระบบจะกำหนดค่านี้เป็นเป้าหมายเริ่มต้นให้อัตโนมัติ โดยผู้ใช้สามารถเลือกปรับเปลี่ยนเป็นเป้าหมายอื่นได้ตลอดเวลา)
- **ตัวเลือกเป้าหมายในระบบ (Goal Options):** ต้องระบุตัวเลือกทั้ง 3 กลุ่มนี้ในเอกสาร Requirements อย่างชัดเจน ห้ามละเว้น ได้แก่
  - กลุ่มทั่วไป: 6,000 / 7,000 / 8,000 ก้าว
  - กลุ่มควบคุมน้ำหนัก: 9,000 / 10,000 / 11,000 / 12,000 ก้าว
  - กลุ่มนักกีฬา: 13,000 / 14,000 / 15,000 ก้าว
- **เงื่อนไขการปรับเป้าหมาย (Goal Change Rules):**
  - **โควต้าการปรับเป้าหมาย:** สามารถกดปรับเปลี่ยนเป้าหมายได้มากที่สุด **วันละ 1 ครั้ง** (โควต้ารีเซ็ตทุก 05:00 น.)
  - **ช่วงเวลาที่มีผล:**
    - หากปรับเปลี่ยนเป้าหมายก่อนเวลา 05:00 น. ➔ มีผลกับรอบวันปัจจุบันทันที
    - หากปรับเปลี่ยนเป้าหมายหลังเวลา 05:00 น. ➔ มีผลในรอบวันถัดไป (เริ่มนับจาก 05:00 น.)
  - **กรณีใช้โควต้าเกิน 1 ครั้ง/วัน:** ปุ่มปรับเป้าหมายต้องถูก Disabled (สีเทาจาง) และแสดง Toast Message เตือนว่า *"คุณสามารถปรับเปลี่ยนเป้าหมายได้เพียง 1 ครั้งต่อวัน"*
  - หากผู้ใช้ไม่ได้กดปรับเปลี่ยน ให้ใช้ค่าเป้าหมายล่าสุดที่เคยเลือกไว้ (หรือค่า Default 8,000 ก้าว)
- **การตัดรอบสถิติประจำวัน:** ข้อมูลนับก้าวและพลังงานทั้งหมดจะถูกรีเซ็ตและตัดรอบใหม่ในเวลา **05:00 น. ของทุกวัน** (รอบวันนับช่วง 05:00 - 04:59 น.)

## 3. ระบบพลังงานและการเปลี่ยนรูปร่างสัตว์เลี้ยง (Pet Visual System)
- คำนวณ % พลังงานจาก: `(ก้าวที่เดินได้จริง / เป้าหมายประจำวัน) * 100` (สะสมสูงสุดไม่เกิน 100%)
- **การแสดงผลรูปร่างสัตว์เลี้ยงตาม % การเดิน (Pet Status Mapping & Code Enum):**
  - **น้อยกว่า 35%:** แสดงผล "อ้วนอืด" (Enum Key: `FAT`)
  - **35% - 69.99%:** แสดงผล "จ่ำม่ำ" (Enum Key: `CHUBBY`)
  - **70% - 99.99%:** แสดงผล "หุ่นลีน (สมส่วน)" (Enum Key: `LEAN`)
  - **ครบ 100% ขึ้นไป:** แสดงผล "มีกล้ามขา" (Enum Key: `MUSCLE`)

## 4. เงื่อนไขทางเทคนิคและการขอสิทธิ์ (Permissions & App Logic)
- **การขอสิทธิ์ (Permission Request):** ขอสิทธิ์เข้าถึงเซนเซอร์นับก้าว (Activity Recognition / Motion & Fitness) เมื่อผู้ใช้เปิดใช้งานครั้งแรก
- **การอัปเดตข้อมูล (Data Refresh):** คำนวณและอัปเดตจำนวนก้าวและเปอร์เซ็นต์หลอดพลังงานทุกครั้งที่เปิดแอป (On App Launch / Resume to Foreground)

## 5. ตารางสถานการณ์ Edge Cases (Must Include 6 Edge Cases)
1. **การปฏิเสธสิทธิ์ (Permission Denied - EC-1):** หากผู้ใช้กดปฏิเสธสิทธิ์ ระบบจะทำการล็อกฟังก์ชันนับก้าวทั้งหมด พร้อมแสดง Pop-up แจ้งเตือนและมีปุ่ม Shortcut พาผู้ใช้ไปหน้า Settings ของเครื่องเพื่อเปิดสิทธิ์
2. **กรณีแบตเตอรี่หมด/ปิดเครื่อง (Battery Drain / Device Shutdown - EC-2):** หากแบตเตอรี่หมดหรือเครื่องดับระหว่างวัน ระบบจะดึงข้อมูลก้าวล่าสุดที่มีการบันทึกไว้ใน Local Storage มาแสดงผลโดยอัตโนมัติทันทีเมื่อเปิดแอปครั้งถัดไป
3. **การเปลี่ยน Timezone หรือเวลาในเครื่อง (Timezone / Clock Modification - EC-3):** หากผู้ใช้เปลี่ยน Timezone หรือปรับเวลาในเครื่องย้อนหลัง ระบบยึดเวลาตาม Network/Server Time เท่านั้น ป้องกันการปรับเวลารีเซ็ตสถิติย้อนหลัง
4. **การสลับอุปกรณ์ (Multi-device Sync - EC-4):** หากผู้ใช้สลับไปใช้อุปกรณ์เครื่องใหม่ระหว่างวัน ระบบจะทำการ Sync เป้าหมายล่าสุดและดึงสถิติก้าวเดินสะสมเฉพาะของวันนั้นมาแสดงผลโดยไม่นับก้าวซ้ำซ้อน
5. **การเปิดแอปค้างไว้ข้ามช่วงเวลา 05:00 น. (Foreground Crossing - EC-5):** หากผู้ใช้เปิดหน้าจอแอปค้างไว้จนถึงเวลา 05:00 น. ระบบต้องทำการตัดรอบสถิติ รีเซ็ตหลอดพลังงานและจำนวนก้าวเป็น 0 และเริ่มรอบวันใหม่อัตโนมัติทันทีโดยไม่ต้อง Restart แอป
6. **กรณีอุปกรณ์ไม่มีฮาร์ดแวร์เซนเซอร์นับก้าว (No Hardware Step Counter - EC-6):** หากอุปกรณ์ของผู้ใช้ไม่มีเซนเซอร์ฮาร์ดแวร์นับก้าว ระบบจะแสดง Pop-up แจ้งเตือนข้อจำกัดของอุปกรณ์ และทำการล็อกฟังก์ชันนับก้าวทั้งหมด (แนวทางเดียวกับ EC-1)

## 6. รายงานสรุปผลรายเดือน (Monthly Health Report System)
- **ขอบเขตงานรอบนี้ (MVP Scope):** ฟังก์ชันส่งออกรายงานสรุปผลประจำเดือนในรูปแบบไฟล์ภาพ PNG 1 หน้าถ้วน ซึ่งรวมข้อมูลทั้ง **การเดิน (Steps)** และ **การดื่มน้ำ (Water)** ไว้ในหน้าเดียวกัน โดยดึงข้อมูลตัวแปรหลัก 4 อย่างมาแสดงตาม Template Figma: ก้าวเดินรวม, ปริมาณน้ำดื่มรวม, ค่าเฉลี่ยรายวัน และจำนวนวันที่ทำเป้าหมายสำเร็จ
- **สิ่งที่ไม่ทำในรอบนี้ (Out of Scope / Future Scope):** 
  - ระบบแจ้งเตือน Push Notification เมื่อเดินใกล้ถึงเป้าหมาย (เช่น แจ้งเตือนเมื่อเดินถึง 80% หรือเหลืออีก 1,000 ก้าว)
  - หน้าแดชบอร์ดสรุปสถิติและกราฟแนวโน้มแสดงผลรายสัปดาห์/รายเดือนภายในแอป (In-App Dashboard)
  - ระบบแข่งขันนับก้าวกับเพื่อนหรือระบบจัดอันดับ (Leaderboard)
  - การเชื่อมต่อกับ Smartwatch หรืออุปกรณ์ภายนอก (Apple Health / Google Fit / Garmin / Fitbit)

# Requirements: การนับก้าวและการตั้งเป้าหมายประจำวัน (steps)

> สถานะ: พร้อมรีวิว · ผู้เขียน: Product agent · ผู้ตรวจ: Senior PM · อ้างอิง Issue: #101

## 1. สรุปฟีเจอร์
ระบบจับการเคลื่อนไหวเพื่อบันทึกก้าวเดินประจำวันของผู้ใช้แบบอัตโนมัติ ตัดรอบสถิติทุก 05:00 น. นำก้าวมาคำนวณ % เป้าหมายเพื่อขับเคลื่อนรูปร่างสัตว์เลี้ยงเสมือนจริง และรองรับการส่งออกรายงานสรุปผลรายเดือนเป็นไฟล์ PNG 1 หน้า
