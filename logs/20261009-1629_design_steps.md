~~~~text
คุณเป็น UX และ Game Designer ของทีม PetPal Health มีหน้าที่แปลง requirements ของฟีเจอร์ให้เป็นประสบการณ์ใช้งานและกติกาที่ทีมพัฒนาสามารถนำไปใช้ได้จริง

คุณให้ความสำคัญกับความเข้าใจง่ายของผู้ใช้ โดยออกแบบลำดับการใช้งานให้ชัดเจน ลดขั้นตอนที่ไม่จำเป็น และไม่สร้างแรงกดดันให้ผู้ใช้เกินความเหมาะสมกับลักษณะของแอป

เมื่อได้รับ requirements ให้ยึดข้อมูลใน requirements เป็นแหล่งข้อมูลหลัก ห้ามสร้างความต้องการใหม่ที่ขัดแย้งกับ requirements หากข้อมูลไม่เพียงพอ ให้ระบุสมมติฐานหรือจุดที่ต้องตัดสินใจอย่างชัดเจน แทนการเดาข้อมูลสำคัญเอง

สำหรับ UX flow ให้ระบุลำดับหน้าจอ จุดเริ่มต้น การกระทำของผู้ใช้ ผลลัพธ์หลังการกระทำ และกรณีสำคัญที่อาจเกิดขึ้น เพื่อให้ Dev สามารถนำไปพัฒนาต่อได้โดยไม่ต้องตีความเองมากเกินไป

สำหรับ game rules ให้ระบุกติกา เงื่อนไข ตัวเลขหรือค่าที่จำเป็น และผลลัพธ์ของแต่ละกรณีอย่างชัดเจน หาก requirements ไม่ได้กำหนดค่าบางอย่าง ให้ระบุว่าเป็นค่าที่ต้องตัดสินใจเพิ่มเติม แทนการสร้างตัวเลขโดยไม่มีเหตุผล

ผลลัพธ์ต้องเขียนอย่างเป็นระบบ ใช้ภาษาไทยที่อ่านง่าย และแยก UX flow กับ game rules ให้ชัดเจน เพื่อให้ Reviewer สามารถตรวจสอบความครบถ้วนและความสอดคล้องกับ requirements ได้ง่าย

คุณทำหน้าที่ออกแบบและให้รายละเอียดสำหรับการพัฒนา ไม่ใช่ผู้เขียนโค้ด และไม่ควรเปลี่ยนแปลง requirements ที่ได้รับมา

ก่อนส่งผลลัพธ์ทุกครั้ง คุณต้องตรวจสอบผลงานของตนเองตามรายการต่อไปนี้

1. ตรวจสอบความครบถ้วนของ Requirements:

* นำ User Stories, Acceptance Criteria และ Edge Cases ทุกข้อจาก requirements มาเทียบกับ UX flow และ game rules
* ระบุว่าข้อกำหนดแต่ละข้อถูกครอบคลุมในส่วนใดของเอกสาร หากข้อใดยังไม่ครอบคลุม ให้แก้ไขเอกสารให้ครบ หรือระบุประเด็นที่ต้องตัดสินใจเพิ่มเติม
* ห้ามละเลยข้อกำหนดเพียงเพราะเป็นกรณีผิดปกติหรือเกิดขึ้นไม่บ่อย

2. ตรวจสอบความสอดคล้อง:

* ตรวจสอบว่า UX flow และ game rules ไม่ขัดแย้งกันเองหรือขัดแย้งกับ requirements
* ตรวจสอบเงื่อนไขก่อนและหลังการกระทำของผู้ใช้ รวมถึงขอบเขตของตัวเลข เช่น ค่าต่ำกว่าขอบเขต เท่ากับขอบเขต และสูงกว่าขอบเขต
* หาก requirements มีข้อความที่อาจตีความได้หลายแบบหรือดูขัดแย้งกัน ให้ระบุข้อความต้นทางและสร้างคำถามเพื่อขอคำยืนยัน ห้ามเลือกคำตอบเองโดยไม่มีหลักฐานรองรับ

3. ตรวจสอบข้อมูลที่ไม่ได้กำหนด:

* ห้ามกำหนดค่าเริ่มต้น ตัวเลข เงื่อนไข ชื่อไฟล์ภาพ หรือพฤติกรรมของระบบขึ้นเอง หาก requirements ไม่ได้ระบุไว้
* หากจำเป็นต้องเสนอแนวทาง ให้แยกข้อเสนอออกจากกติกาที่กำหนดแล้ว และติดป้ายว่าเป็นข้อเสนอหรือประเด็นรอยืนยันจาก Product
* ห้ามอ้างว่ามีไฟล์ภาพหรือ assets อยู่จริง หากไม่ได้รับข้อมูลยืนยันจาก requirements หรือรายการไฟล์ที่มีอยู่

4. ตรวจสอบความครบถ้วนของ UX:

* ระบุหน้าจอ จุดเริ่มต้น ลำดับการใช้งาน การกระทำของผู้ใช้ ผลลัพธ์ และสถานะผิดปกติที่เกี่ยวข้อง
* ตรวจสอบว่ามีแนวทางสำหรับ Permission Denied, การรีเซ็ตข้อมูลประจำวัน, การเปิดแอปค้างข้ามเวลาตัดรอบ และกรณีอื่นที่ requirements ระบุไว้
* สำหรับฟีเจอร์รายงาน ให้ตรวจว่าข้อมูลและผลลัพธ์ที่แสดงหรือส่งออกครอบคลุม Acceptance Criteria ครบถ้วน

5. ตรวจสอบรูปแบบเอกสาร:

* แยก UX flow และ game rules ให้ชัดเจน ใช้ภาษาไทยที่อ่านง่าย และใช้ชื่อหน้าจอ ตัวแปร และสถานะอย่างสม่ำเสมอ
* ตรวจสอบตาราง หัวข้อ รายการ และคำถามถึง Product ว่าไม่มีเนื้อหาซ้ำโดยไม่จำเป็น
* ตรวจสอบว่าชื่อไฟล์ภาพเป็นเพียงข้อเสนอเมื่อยังไม่มีไฟล์จริง และแยกข้อเสนอออกจาก assets ที่ยืนยันแล้ว

ก่อนจบงาน ให้สรุปประเด็นที่ตรวจพบและคำถามที่ยังต้องให้ Product ตัดสินใจ โดยไม่เปลี่ยน requirements หรือสร้างคำตอบแทน Product
~~~~

# Requirements: การนับก้าวและการตั้งเป้าหมายประจำวัน (steps)

> สถานะ: พร้อมรีวิว · ผู้เขียน: Product agent · ผู้ตรวจ: Tech Lead & QA Lead · อ้างอิง Issue: #101

## 1. สรุปฟีเจอร์
ฟีเจอร์ระบบนับก้าวเดินประจำวัน (Passive Tracking) ทำหน้าที่ติดตามการเคลื่อนไหวของผู้ใช้และตัดรอบสถิติใหม่ทุกวันเวลา 05:00 น. เพื่อคำนวณพลังงาน (% Goal) นำไปแสดงผลการเปลี่ยนแปลงรูปร่างของสัตว์เลี้ยงเสมือนจริงในแอป PetPal Health ช่วยกระตุ้นให้ผู้ใช้เดินออกกำลังกายร่วมกับสัตว์เลี้ยงอย่างต่อเนื่อง

## 2. ตารางแสดงสถานะสัตว์เลี้ยงตามเปอร์เซ็นต์การเดิน (Pet Status Mapping)
| เปอร์เซ็นต์การเดิน (% Goal) | สถานะและรูปร่างของสัตว์เลี้ยง |
|---|---|
| < 35% | อ้วนอืด |
| 35% - 69.99% | จ่ำม่ำ |
| 70% - 99.99% | หุ่นลีน (สมส่วน) |
| 100% ขึ้นไป | มีกล้ามขา |

| EC-4 | **การสลับอุปกรณ์ (Multi-device Sync):** ผู้ใช้สลับไปใช้งานสมาร์ตโฟนเครื่องใหม่ด้วยบัญชีเดิมระหว่างวัน | ระบบดึงข้อมูลเป้าหมายล่าสุดและ Sync สถิติก้าวเดินสะสมเฉพาะของวันนั้นมาจากเซิร์ฟเวอร์โดยไม่นับก้าวซ้ำซ้อน |
| EC-5 | **การเปิดแอปค้างไว้ข้ามช่วงเวลา 05:00 น. (Foreground Crossing):** ผู้ใช้เปิดหน้าจอแอปทิ้งไว้ข้ามผ่านเวลา 05:00:00 น. | ระบบทำการรีเฟรชหน้าจออัตโนมัติ ตัดรอบสถิติ รีเซ็ตหลอดพลังงานและจำนวนก้าวเป็น 0 และเริ่มนับรอบวันใหม่ทันทีโดยไม่ต้องปิดเปิดแอปใหม่ |

# Requirements: การนับก้าวและการตั้งเป้าหมายประจำวัน (steps)

> สถานะ: พร้อมรีวิว · ผู้เขียน: Product agent · ผู้ตรวจ: Tech Lead & QA Lead · อ้างอิง Issue: #101

## 1. สรุปฟีเจอร์
ฟีเจอร์ระบบนับก้าวเดินประจำวัน (Passive Tracking) ทำหน้าที่ติดตามการเคลื่อนไหวของผู้ใช้และตัดรอบสถิติใหม่ทุกวันเวลา 05:00 น. เพื่อคำนวณพลังงาน (% Goal) นำไปแสดงผลการเปลี่ยนแปลงรูปร่างของสัตว์เลี้ยงเสมือนจริงในแอป PetPal Health ช่วยกระตุ้นให้ผู้ใช้เดินออกกำลังกายร่วมกับสัตว์เลี้ยงอย่างต่อเนื่อง

## 2. ตารางแสดงสถานะสัตว์เลี้ยงตามเปอร์เซ็นต์การเดิน (Pet Status Mapping)
| เปอร์เซ็นต์การเดิน (% Goal) | สถานะและรูปร่างของสัตว์เลี้ยง |
|---|---|
| < 35% | อ้วนอืด |
| 35% - 69.99% | จ่ำม่ำ |
| 70% - 99.99% | หุ่นลีน (สมส่วน) |
| 100% ขึ้นไป | มีกล้ามขา |

~~~~text
2. ผู้ใช้เดินออกกำลังกายระหว่างวัน ระบบอัปเดตจำนวนก้าวและ % Goal อัตโนมัติ รูปร่างของสัตว์เลี้ยงบนหน้าจอหลัก (S-1) จะเปลี่ยนไปตามช่วงเปอร์เซ็นต์ (เช่น ถึง 50% เปลี่ยนเป็น "จ่ำม่ำ" ตาม AC-5 หรือถึง 100% เปลี่ยนเป็น "มีกล้ามขา" ตาม AC-6)
3. หากผู้ใช้ต้องการเปลี่ยนเป้าหมายประจำวัน (US-2 / AC-2) ผู้ใช้กดปุ่ม "ตั้งค่าเป้าหมายก้าวเดิน" บนหน้าจอหลัก (S-1) เข้าสู่หน้า S-2 เลือกกลุ่มควบคุมน้ำหนัก (9,000 / 10,000 / 11,000 / 12,000 ก้าว) แล้วกด "ยืนยันเป้าหมาย" ระบบบันทึกเป้าหมายทันทีและหลอดพลังงานคำนวณจากเป้าหมายใหม่
4. เมื่อถึงเวลา 05:00:00 น. ของวันถัดไป (US-1 / AC-7 / AC-5) ระบบจะทำการตัดรอบวันโดยอัตโนมัติ จำนวนก้าวและหลอดพลังงานจะถูกรีเซ็ตเป็น 0 และสิทธิ์การเปลี่ยนเป้าหมายในวันใหม่จะถูกรีเซ็ตเป็น 0 ครั้ง
5. ผู้ใช้ต้องการตรวจสอบสรุปผลรายเดือน (US-5 / AC-8) จากหน้าจอหลัก (S-1) กดเข้าสู่หน้าสรุปผลรายเดือน (S-3) แล้วกดปุ่ม "Export PNG Card" ระบบประมวลผลและแสดงไฟล์รูปภาพ PNG 1 หน้าถ้วนที่รวมข้อมูลการเดินและน้ำดื่มครบถ้วน
~~~~

## 5. Edge cases

| ID | สถานการณ์ | ผลที่คาดหวังที่ทดสอบได้ |
|---|---|---|
| EC-1 | **การปฏิเสธสิทธิ์ (Permission Denied):** ผู้ใช้กดปฏิเสธสิทธิ์การเข้าถึงเซนเซอร์นับก้าว | ระบบล็อกฟังก์ชันนับก้าวทั้งหมด แสดง Pop-up แจ้งเตือน และแสดงปุ่ม Shortcut พาผู้ใช้ไปยังหน้า Settings ของระบบปฏิบัติการเพื่อเปิดสิทธิ์ |
| EC-2 | **กรณีแบตเตอรี่หมด/ปิดเครื่อง:** เครื่องดับระหว่างวันเนื่องจากแบตเตอรี่หมด และเปิดเครื่องขึ้นมาใหม่ | ระบบดึงข้อมูลก้าวล่าสุดที่บันทึกไว้ใน Local Storage มาแสดงผลทันทีโดยไม่มีข้อมูลสูญหาย |
| EC-3 | **การเปลี่ยน Timezone หรือเวลาในเครื่อง:** ผู้ใช้เปลี่ยนโซนเวลาหรือปรับนาฬิกาย้อนหลังเพื่อหลอกระบบรีเซ็ตสถิติ | ระบบยึดเวลาตาม Network/Server Time เท่านั้น ป้องกันการรีเซ็ตสถิติย้อนหลัง และจำนวนก้าวไม่ถูกแก้ไข |
| EC-4 | **การสลับอุปกรณ์ (Multi-device Sync):** ผู้ใช้สลับไปใช้งานสมาร์ตโฟนเครื่องใหม่ด้วยบัญชีเดิมระหว่างวัน | ระบบดึงข้อมูลเป้าหมายล่าสุดและ Sync สถิติก้าวเดินสะสมเฉพาะของวันนั้นมาจากเซิร์ฟเวอร์โดยไม่นับก้าวซ้ำซ้อน |
| EC-5 | **การเปิดแอปค้างไว้ข้ามช่วงเวลา 05:00 น. (Foreground Crossing):** ผู้ใช้เปิดหน้าจอแอปทิ้งไว้ข้ามผ่านเวลา 05:00:00 น. | ระบบทำการรีเฟรชหน้าจออัตโนมัติ ตัดรอบสถิติ รีเซ็ตหลอดพลังงานและจำนวนก้าวเป็น 0 และเริ่มนับรอบวันใหม่ทันทีโดยไม่ต้องปิดเปิดแอปใหม่ |

## 3. ขั้นตอนการใช้งาน (happy path)

1. ผู้ใช้เปิดแอปพลิเคชัน PetPal Health ครั้งแรก (US-1 / AC-1) ระบบจะแสดง Pop-up ขอสิทธิ์ Activity Recognition ผู้ใช้กด "อนุญาตสิทธิ์" ระบบเริ่มนับก้าวและแสดงตัวเลข 0 ก้าวขึ้นไปบนหน้าจอหลัก (S-1) พร้อมแสดงสัตว์เลี้ยงในสถานะ "อ้วนอืด" (< 35%)
2. ผู้ใช้เดินออกกำลังกายระหว่างวัน ระบบอัปเดตจำนวนก้าวและ % Goal อัตโนมัติ รูปร่างของสัตว์เลี้ยงบนหน้าจอหลัก (S-1) จะเปลี่ยนไปตามช่วงเปอร์เซ็นต์ (เช่น ถึง 50% เปลี่ยนเป็น "จ่ำม่ำ" ตาม AC-5 หรือถึง 100% เปลี่ยนเป็น "มีกล้ามขา" ตาม AC-6)
3. หากผู้ใช้ต้องการเปลี่ยนเป้าหมายประจำวัน (US-2 / AC-2) ผู้ใช้กดปุ่ม "ตั้งค่าเป้าหมายก้าวเดิน" บนหน้าจอหลัก (S-1) เข้าสู่หน้า S-2 เลือกกลุ่มควบคุมน้ำหนัก (9,000 / 10,000 / 11,000 / 12,000 ก้าว) แล้วกด "ยืนยันเป้าหมาย" ระบบบันทึกเป้าหมายทันทีและหลอดพลังงานคำนวณจากเป้าหมายใหม่
4. เมื่อถึงเวลา 05:00:00 น. ของวันถัดไป (US-1 / AC-7 / AC-5) ระบบจะทำการตัดรอบวันโดยอัตโนมัติ จำนวนก้าวและหลอดพลังงานจะถูกรีเซ็ตเป็น 0 และสิทธิ์การเปลี่ยนเป้าหมายในวันใหม่จะถูกรีเซ็ตเป็น 0 ครั้ง
5. ผู้ใช้ต้องการตรวจสอบสรุปผลรายเดือน (US-5 / AC-8) จากหน้าจอหลัก (S-1) กดเข้าสู่หน้าสรุปผลรายเดือน (S-3) แล้วกดปุ่ม "Export PNG Card" ระบบประมวลผลและแสดงไฟล์รูปภาพ PNG 1 หน้าถ้วนที่รวมข้อมูลการเดินและน้ำดื่มครบถ้วน

~~~~text
| **การเปิดแอปค้างไว้ข้ามช่วงเวลา 05:00 น. (Foreground Crossing):** ผู้ใช้เปิดหน้าจอแอปทิ้งไว้ข้ามผ่านเวลา 05:00:00 น. | ระบบทำการรีเฟรชหน้าจออัตโนมัติ ตัดรอบสถิติ รีเซ็ตหลอดพลังงานและจำนวนก้าวเป็น 0 และเริ่มนับรอบวันใหม่ทันทีโดยไม่ต้องปิดเปิดแอปใหม่ |
~~~~

~~~~text
## 3. ขั้นตอนการใช้งาน (happy path)

1. ผู้ใช้เปิดแอปพลิเคชัน PetPal Health ครั้งแรก (US-1 / AC-1) ระบบจะแสดง Pop-up ขอสิทธิ์ Activity Recognition ผู้ใช้กด "อนุญาตสิทธิ์" ระบบเริ่มนับก้าวและแสดงตัวเลข 0 ก้าวขึ้นไปบนหน้าจอหลัก (S-1) พร้อมแสดงสัตว์เลี้ยงในสถานะ "อ้วนอืด" (< 35%)
2. ผู้ใช้เดินออกกำลังกายระหว่างวัน ระบบอัปเดตจำนวนก้าวและ % Goal อัตโนมัติ รูปร่างของสัตว์เลี้ยงบนหน้าจอหลัก (S-1) จะเปลี่ยนไปตามช่วงเปอร์เซ็นต์ (เช่น ถึง 50% เปลี่ยนเป็น "จ่ำม่ำ" ตาม AC-5 หรือถึง 100% เปลี่ยนเป็น "มีกล้ามขา" ตาม AC-6)
3. หากผู้ใช้ต้องการเปลี่ยนเป้าหมายประจำวัน (US-2 / AC-2) ผู้ใช้กดปุ่ม "ตั้งค่าเป้าหมายก้าวเดิน" บนหน้าจอหลัก (S-1) เข้าสู่หน้า S-2 เลือกกลุ่มควบคุมน้ำหนัก (9,000 / 10,000 / 11,000 / 12,000 ก้าว) แล้วกด "ยืนยันเป้าหมาย" ระบบบันทึกเป้าหมายทันทีและหลอดพลังงานคำนวณจากเป้าหมายใหม่
4. เมื่อถึงเวลา 05:00:00 น. ของวันถัดไป (US-1 / AC-7 / AC-5) ระบบจะทำการตัดรอบวันโดยอัตโนมัติ จำนวนก้าวและหลอดพลังงานจะถูกรีเซ็ตเป็น 0 และสิทธิ์การเปลี่ยนเป้าหมายในวันใหม่จะถูกรีเซ็ตเป็น 0 ครั้ง
5. ผู้ใช้ต้องการตรวจสอบสรุปผลรายเดือน (US-5 / AC-8) จากหน้าจอหลัก (S-1) กดเข้าสู่หน้าสรุปผลรายเดือน (S-3) แล้วกดปุ่ม "Export PNG Card" ระบบประมวลผลและแสดงไฟล์รูปภาพ PNG 1 หน้าถ้วนที่รวมข้อมูลการเดินและน้ำดื่มครบถ้วน
~~~~

~~~~text
| เหตุการณ์ | ค่าก่อน | ค่าหลัง | หมายเหตุ |

## 4. พฤติกรรมที่ขอบเขต

| กรณี | ผลลัพธ์ที่ทดสอบได้ |
|---|---|
| **ค่าเปอร์เซ็นต์ก้าวเดินเกิน 100% (High Bound / Max Cap):** ผู้ใช้เดินได้เกินกว่าเป้าหมายที่ตั้งไว้ (เช่น 120% หรือเกิน 100%) | หลอดพลังงานและเปอร์เซ็นต์สะสมหยุดแสดงผลสูงสุดอยู่ที่ 100% และรูปร่างสัตว์เลี้ยงคงสถานะ "มีกล้ามขา" ไว้ตลอดวันจนกว่าจะถึงรอบตัด 05:00 น. |
| **การปฏิเสธสิทธิ์ (Permission Denied):** ผู้ใช้กดปฏิเสธสิทธิ์การเข้าถึงเซนเซอร์นับก้าว | ระบบล็อกฟังก์ชันนับก้าวทั้งหมด แสดง Pop-up แจ้งเตือน พร้อมแสดงปุ่ม Shortcut พาผู้ใช้ไปยังหน้า Settings ของระบบปฏิบัติการเพื่อเปิดสิทธิ์ (แสดงภาพ `assets/images/permission_banner.png`) |
| **กรณีแบตเตอรี่หมด/ปิดเครื่อง:** เครื่องดับระหว่างวันเนื่องจากแบตเตอรี่หมด และเปิดเครื่องขึ้นมาใหม่ | ระบบดึงข้อมูลก้าวล่าสุดที่บันทึกไว้ใน Local Storage มาแสดงผลทันทีโดยไม่มีข้อมูลสูญหาย (Local Persistence) |
| **การเปลี่ยน Timezone หรือเวลาในเครื่อง:** ผู้ใช้เปลี่ยนโซนเวลาหรือปรับนาฬิกาย้อนหลังเพื่อหลอกระบบรีเซ็ตสถิติ | ระบบยึดเวลาตาม Network/Server Time เท่านั้น ป้องกันการรีเซ็ตสถิติย้อนหลัง และจำนวนก้าวไม่ถูกแก้ไข |
| **การสลับอุปกรณ์ (Multi-device Sync):** ผู้ใช้สลับไปใช้งานสมาร์ตโฟนเครื่องใหม่ด้วยบัญชีเดิมระหว่างวัน | ระบบดึงข้อมูลเป้าหมายล่าสุดและ Sync สถิติก้าวเดินสะสมเฉพาะของวันนั้นมาจากเซิร์ฟเวอร์โดยไม่นับก้าวซ้ำซ้อน |
| **การเปิดแอปค้างไว้ข้ามช่วงเวลา 05:00 น. (Foreground Crossing):** ผู้ใช้เปิดหน้าจอแอปทิ้งไว้ข้ามผ่านเวลา 05:00:00 น. | ระบบทำการรีเฟรชหน้าจออัตโนมัติ ตัดรอบสถิติ รีเซ็ตหลอดพลังงานและจำนวนก้าวเป็น 0 และเริ่มนับรอบวันใหม่ทันทีโดยไม่ต้องปิดเปิดแอปใหม่ |
~~~~
