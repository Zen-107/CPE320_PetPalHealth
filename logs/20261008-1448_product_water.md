# Requirements: ฟีเจอร์การบันทึกการกินน้ำ (water)

> สถานะ: พร้อมรีวิว · ผู้เขียน: Product agent · ผู้ตรวจ: เพื่อน A · อ้างอิง Issue: #101

## 1. สรุปฟีเจอร์
ฟีเจอร์การบันทึกการกินน้ำช่วยให้ผู้ใช้สามารถบันทึกปริมาณน้ำดื่มในแต่ละวันเพื่อสุขภาพที่ดี พร้อมเชื่อมโยงกับหลอดพลังงานและอารมณ์ของสัตว์เลี้ยงในแอป PetPal Health โดยมีระบบป้องกันการกดรัว (Anti-Spam) และรีเซ็ตข้อมูลอัตโนมัติทุกวัน

## 2. User stories

| ID | ในฐานะ | ฉันอยาก | เพื่อ |
|---|---|---|---|
| US-1 | ผู้ใช้แอป PetPal Health | กดบันทึกการดื่มน้ำทีละแก้ว | เพิ่มหลอดพลังงานน้ำและดูแลสุขภาพสัตว์เลี้ยงของฉัน |
| US-2 | ผู้ใช้แอป PetPal Health | เห็นสถานะและอารมณ์ของสัตว์เลี้ยงเปลี่ยนไปตามปริมาณน้ำที่ดื่ม | ทราบว่าสัตว์เลี้ยงมีความสุขหรือต้องการการดูแลเมื่อดื่มน้ำครบตามเป้าหมาย |
| US-3 | ผู้ใช้แอป PetPal Health | ได้รับการแจ้งเตือนเมื่อพยายามบันทึกน้ำเกินโควต้าในเวลาที่กำหนด | ป้องกันการกดบันทึกรัวโดยไม่ตั้งใจ (Anti-Spam) |
| US-4 | ผู้ใช้แอป PetPal Health | ให้ระบบรีเซ็ตหลอดพลังงานและจำนวนแก้วน้ำเป็น 0 ทุกวันตอนตี 5 | เริ่มต้นบันทึกใหม่ได้อย่างถูกต้องในวันถัดไป |

## 3. Acceptance criteria

| ID | อ้างถึง | เงื่อนไข (ก่อน / เมื่อ / แล้ว) | ค่าที่ทดสอบได้ |
|---|---|---|---|
| AC-1 | US-1 | เมื่อผู้ใช้กดปุ่มบันทึกน้ำ 1 ครั้ง | หลอดพลังงานเพิ่มขึ้น 12.5% และจำนวนแก้วน้ำเพิ่มขึ้น 1 แก้ว |
| AC-2 | US-2 | เมื่อหลอดพลังงานอยู่ระหว่าง 0% - 29% (0 - 2 แก้ว) | สัตว์เลี้ยงแสดงสถานะ: "เหี่ยวเฉา ป่วย ใกล้ตาย" |
| AC-3 | US-2 | เมื่อหลอดพลังงานอยู่ระหว่าง 30% - 59% (3 - 4 แก้ว) | สัตว์เลี้ยงแสดงสถานะ: "เริ่มเพลีย อ่อนแรง แลบลิ้น" |
| AC-4 | US-2 | เมื่อหลอดพลังงานอยู่ระหว่าง 60% - 100% (5 - 8+ แก้ว) | สัตว์เลี้ยงแสดงสถานะ: "สดชื่น ร่าเริง มีความสุข" |
| AC-5 | US-3 | เมื่อผู้ใช้กดบันทึกน้ำครบ 2 ครั้งภายในช่วงเวลา 5 นาที แล้วกดครั้งที่ 3 | ระบบแสดง Toast warning แจ้งเตือนติด Cooldown และไม่อนุญาตให้เพิ่มจำนวนแก้ว |
| AC-6 | US-4 | เมื่อเวลาถึง 05:00 น. ของวันใหม่ | หลอดพลังงานน้ำและจำนวนแก้วน้ำสะสมถูกรีเซ็ตกลับเป็น 0% และ 0 แก้วโดยอัตโนมัติ |

## 4. Edge cases

| ID | สถานการณ์ | ผลที่คาดหวัง |
|---|---|---|
| EC-1 | ผู้ใช้ดื่มน้ำเกิน 8 แก้ว (เช่น แก้วที่ 9 ขึ้นไป) | หลอดพลังงานหยุดสะสมสูงสุดที่ 100% และสัตว์เลี้ยงยังคงรักษาสถานะ "สดชื่น ร่าเริง มีความสุข" ไว้ |
| EC-2 | ผู้ใช้พยายามกดบันทึกน้ำครั้งที่ 3 หลังจากผ่านไป 4 นาที 59 วินาทีจากครั้งแรก | ระบบยังคงบล็อกการกดและแสดง Toast warning จนกว่าจะครบกำหนด 5 นาที |
| EC-3 | แอปพลิเคชันถูกปิดและเปิดใหม1ในช่วงเวลาก่อน 05:00 น. | ข้อมูลจำนวนแก้วและเวลาบันทึกล่าสุดยังคงถูกต้องตาม Local Storage |

## 5. สิ่งที่ไม่ทำในรอบนี้ (Out of scope)
- ไม่มีระบบลดพลังงานน้ำตามเวลาระหว่างวัน (Decay)
- ยังไม่ต่อ Backend หรือ Server ภายนอก
- ยังไม่มีระบบ Social / ดูเพื่อนร่วมกัน
- ยังไม่มีระบบซื้อของแต่งตัวสัตว์เลี้ยงเพิ่มเติม

## 6. ข้อมูลที่ใช้ (ข้อมูลสมมติเท่านั้น)

| ข้อมูล | ชนิด/หน่วย | เก็บที่ไหน |
|---|---|---|
| water_count | Integer (แก้ว) | Local Storage (SharedPreferences / Hive) |
| water_energy_percentage | Float (%) | Local Storage (SharedPreferences / Hive) |
| last_logged_timestamps | List of Timestamps (เวลา) | Local Storage (SharedPreferences / Hive) |
| last_reset_date | String (YYYY-MM-DD) | Local Storage (SharedPreferences / Hive) |

## 7. คำถามที่ยังเปิดอยู่
- รูปแบบของ Toast warning ในหน้าจอควรใช้ดีไซน์ไอקอนสุนัข/แมวเตือน หรือเป็นข้อความแจ้งเตือนมาตรฐานของแอปพลิเคชัน
- ควรมีเสียง Sound Effect ประกอบเมื่อสัตว์เลี้ยงเปลี่ยนสถานะอารมณ์หรือไม่
