## 3. ขั้นตอนการใช้งาน (happy path)
1. เปิดแอปครั้งแรก: ผู้ใช้เปิดแอป PetPal Health → ระบบแสดงหน้าจอ S-4 ขอสิทธิ์ Activity Recognition → ผู้ใช้กด "อนุญาตสิทธิ์" → ระบบเข้าสู่หน้าจอ S-1 (หน้าจอหลัก) พร้อมเริ่มนับก้าว (0 ก้าวขึ้นไป)
2. การดูสถานะสัตว์เลี้ยง: ผู้ใช้เดินออกกำลังกาย → เซนเซอร์อัปเดตจำนวนก้าว current_steps → เปอร์เซ็นต์ % Goal คำนวณเปลี่ยนไป → หน้าจอ S-1 อัปเดตรูปร่างสัตว์เลี้ยงตามช่วงเปอร์เซ็นต์ (เช่น "จ่ำม่ำ" หรือ "มีกล้ามขา") ทันที
3. การเปลี่ยนเป้าหมายประจำวัน: ผู้ใช้กดปุ่ม "เปลี่ยนเป้าหมาย" บนหน้า S-1 → ระบบพามาหน้า S-2 → ผู้ใช้เลือกตัวเลือกเป้าหมาย (เช่น 10,000 ก้าว) และกด "ยืนยันเป้าหมาย" → ระบบบันทึกเป้าหมายใหม่ทันที และกลับมาแสดงผลที่หน้า S-1
4. การส่งออกรายงานรายเดือน: ผู้ใช้กดปุ่ม "ดูสรุปผลรายเดือน" บนหน้า S-1 → ระบบแสดงหน้า S-3 → ผู้ใช้กดปุ่ม "Export PNG Card" → ระบบสร้างไฟล์รูปภาพสรุปผลรายเดือนให้ผู้ใช้

## 4. สถานะของหน้าจอ

| หน้าจอ | สถานะ | เงื่อนไขที่ทำให้เกิด | สิ่งที่แสดง |
|---|---|---|---|
| S-1 | ปกติ | ทำงานปกติ มีสิทธิ์เข้าถึงเซนเซอร์ | แสดงตัวเลขก้าว, หลอดพลังงาน, และรูปร่างสัตว์เลี้ยงตามจริง |
| S-1 | ว่าง (Zero State) | เพิ่งเปิดแอปครั้งแรกของวัน หรือเพิ่งผ่านเวลา 05:00:00 น. | แสดงก้าวเป็น "0 / 10,000 ก้าว" และสัตว์เลี้ยงอยู่ในสถานะเริ่มต้น |
| S-4 | ผิดพลาด (Permission Denied) | ผู้ใช้กดปฏิเสธสิทธิ์การเข้าถึงเซนเซอร์นับก้าว (EC-1) | แสดงปุ่ม Shortcut "ไปที่การตั้งค่าเครื่อง" และข้อความล็อกฟังก์ชันนับก้าว |
| S-2 | ผิดพลาด (Limit Exceeded) | ผู้ใช้พยายามเปลี่ยนเป้าหมายเป็นครั้งที่ 2 ในวันเดียวกัน (AC-3) | ปุ่มยืนยันเป้าหมายถูก Disabled (เป็นสีเทา) และแสดงข้อความแจ้งเตือน "คุณสามารถปรับเปลี่ยนเป้าหมายได้เพียง 1 ครั้งต่อวันเท่านั้น" |

## 6. คำถามถึง Product
- รูปแบบการแจ้งเตือน (Push Notification) เมื่อผู้ใช้ใกล้ทำเป้าหมายสำเร็จ 100% ควรส่งล่วงหน้าที่ก้าวเท่าไหร่ (เช่น เหลืออีก 500 ก้าว)? (ยังไม่มีกำหนดใน requirements)
- ในกรณีที่อุปกรณ์ของผู้ใช้ไม่มีฮาร์ดแวร์เซนเซอร์นับก้าว (Hardware Step Counter) ระบบจะมี Fallback อย่างไร หรือบังคับรองรับเฉพาะเครื่องที่มีเซนเซอร์เท่านั้น? (ยังไม่มีกำหนดใน requirements)
