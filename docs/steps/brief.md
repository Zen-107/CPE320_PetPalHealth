# Brief: ฟีเจอร์นับก้าวและการตั้งเป้าหมายประจำวัน (Step Tracking & Daily Goal)

## 1. ภาพรวมฟีเจอร์ (Overview)
ระบบจับการเคลื่อนไหวเพื่อนับก้าวเดินของผู้ใช้แบบทั้งวัน (Passive Tracking) โดยตัดรอบสถิติประจำวันตอนเวลา 05:00 น. เพื่อนำก้าวเดินมาคำนวณเป็นพลังงาน (% Goal) ที่ส่งผลต่อรูปร่างของสัตว์เลี้ยงเสมือนจริงในแอป PetPal Health

## 2. การตั้งและปรับเปลี่ยนเป้าหมาย (Goal Setting & Logic)
- **การเลือกเป้าหมายครั้งแรก (Goal Options):** มีตัวเลือก 3 กลุ่ม ได้แก่
  - กลุ่มทั่วไป: 6,000 / 7,000 / 8,000 ก้าว
  - กลุ่มควบคุมน้ำหนัก: 9,000 / 10,000 / 11,000 / 12,000 ก้าว
  - กลุ่มนักกีฬา: 13,000 / 14,000 / 15,000 ก้าว
- **เงื่อนไขการปรับเป้าหมาย:**
  - สามารถปรับเปลี่ยนเป้าหมายได้มากที่สุด **วันละ 1 ครั้ง**
  - การปรับเป้าหมายก่อนเวลา 05:00 น. จะมีผลกับวันนั้นทันที
  - การปรับเป้าหมายหลังเวลา 05:00 น. จะเริ่มมีผลใน **วันถัดไป (นับจาก 05:00 น.)**
  - หากพยายามปรับเปลี่ยนซ้ำเกิน 1 ครั้งในวันเดียวกัน ปุ่มปรับเป้าหมายจะถูก Disabled และแสดงข้อความแจ้งเตือน
  - หากไม่มีการปรับเปลี่ยน จะใช้ค่าเป้าหมายล่าสุดที่เคยตั้งไว้
- **การรีเซ็ตสถิติ:** ข้อมูลนับก้าวและพลังงานทั้งหมดจะถูกรีเซ็ตและตัดรอบใหม่ในเวลา **05:00 น. ของทุกวัน** (นับช่วง 05:00 - 04:59 น.)

## 3. ระบบพลังงานและการเปลี่ยนรูปร่างสัตว์เลี้ยง (Pet Visual System)
- คำนวณ % พลังงานจาก: (ก้าวที่เดินได้จริง / เป้าหมายประจำวัน) * 100 (สะสมสูงสุดไม่เกิน 100%)
- **การแสดงผลรูปร่างของสัตว์เลี้ยงตาม % การเดิน:**
  - **น้อยกว่า 35%:** รูปร่างอ้วนอืด
  - **35% - 69.99%:** รูปร่างจ่ำม่ำ
  - **70% - 99.99%:** รูปร่างลีน (หุ่นสมส่วน)
  - **ครบ 100% ขึ้นไป:** รูปร่างฟิตมีกล้ามขา

## 4. เงื่อนไขทางเทคนิคและการขอสิทธิ์ (Permissions & App Logic)
- **การขอสิทธิ์ (Permission Request):** ต้องขอสิทธิ์เข้าถึงเซนเซอร์นับก้าว (Activity Recognition / Motion & Fitness) ก่อนเริ่มใช้งานเสมอ
- **การอัปเดตข้อมูล (Data Refresh):** อัปเดตจำนวนก้าวและเปอร์เซ็นต์หลอดพลังงานทุกครั้งที่เปิดแอป (On App Launch / Resume to Foreground)

## 5. สถานการณ์ Edge Cases ที่ต้องสรุปในตาราง (Must Include 5 Edge Cases in Requirements Table)
1. **การปฏิเสธสิทธิ์ (Permission Denied):** หากผู้ใช้ปฏิเสธสิทธิ์ ระบบจะทำการล็อกฟังก์ชันนับก้าวทั้งหมด พร้อมแสดง Pop-up แจ้งเตือนและมีปุ่ม Shortcut พาย้ายไปหน้า Settings ของเครื่องเพื่อเปิดสิทธิ์
2. **กรณีแบตเตอรี่หมด/ปิดเครื่อง:** หากแบตเตอรี่หมดหรือเครื่องดับระหว่างวัน ระบบจะดึงข้อมูลก้าวล่าสุดที่มีการบันทึกไว้ใน Local Storage มาแสดงผลโดยอัตโนมัติทันทีเมื่อเปิดแอปครั้งถัดไป
3. **การเปลี่ยน Timezone หรือเวลาในเครื่อง:** หากผู้ใช้เปลี่ยน Timezone หรือปรับเวลาในเครื่องย้อนหลัง ระบบยึดเวลาตาม Network/Server Time เท่านั้น ป้องกันการปรับเวลารีเซ็ตสถิติย้อนหลัง
4. **การสลับอุปกรณ์ (Multi-device Sync):** หากผู้ใช้สลับไปใช้อุปกรณ์เครื่องใหม่ระหว่างวัน ระบบจะทำการ Sync เป้าหมายล่าสุดและดึงสถิติก้าวเดินสะสมเฉพาะของวันนั้นมาแสดงผลโดยไม่นับก้าวซ้ำซ้อน
5. **การเปิดแอปค้างไว้ข้ามช่วงเวลา 05:00 น. (Foreground Crossing):** หากผู้ใช้เปิดหน้าจอแอปค้างไว้จนถึงเวลา 05:00 น. ระบบต้องทำการตัดรอบสถิติ รีเซ็ตหลอดพลังงานและจำนวนก้าวเป็น 0 และเริ่มรอบวันใหม่อัตโนมัติทันที

## 6. รายงานสรุปผลรายเดือน (Monthly Health Report System)
- **สโคปหลักรอบนี้ (MVP Scope):** ฟังก์ชั่นส่งออกเอกสารสรุปผลประจำเดือนในฟอร์แมต Image (PNG Card) 1 หน้าถ้วน รวมข้อมูลทั้ง **การเดิน (Steps)** และ **การดื่มน้ำ (Water)** ไว้ในหน้าเอกสารเดียวกัน (ก้าวเดินรวม, ปริมาณน้ำดื่มรวม, ค่าเฉลี่ยรายวัน, และจำนวนวันที่ทำได้ตามเป้าหมาย)
- **สิ่งที่ไม่ทำในรอบนี้ (Out of Scope / Future Scope):** 
  - หน้าแดชบอร์ดสรุปสถิติและกราฟแนวโน้มแสดงผลในแอป (In-App Dashboard)
  - ระบบแข่งขันนับก้าวกับเพื่อน (Leaderboard)
  - การเชื่อมต่อกับ Smartwatch หรืออุปกรณ์ภายนอก
