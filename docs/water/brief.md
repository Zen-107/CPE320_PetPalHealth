# Brief: ฟีเจอร์การบันทึกการกินน้ำ (Water Intake Tracking)

> เจ้าของ: เพื่อน A — โจทย์ตั้งต้นที่ Product agent อ่านก่อนเขียน requirements.md

## 1. ผู้ใช้ทำอะไรในฟีเจอร์นี้ และทำไมถึงอยากทำ
- ผู้ใช้กดบันทึกปริมาณการดื่มน้ำในชีวิตประจำวันเพื่อส่งเสริมสุขภาพการดื่มน้ำของตนเอง
- มีเป้าหมายคือดื่มน้ำอย่างน้อย 8 แก้วต่อวัน (1 แก้ว = 12.5% เพิ่มหลอดพลังงานสะสม)
- ป้องกันการสแปมกดบันทึก โดยจำกัดให้กดได้ไม่เกิน 2 ครั้ง ต่อ 5 นาที
- ข้อมูลและหลอดพลังงานจะถูกรีเซ็ตเป็น 0 ตอน 05:00 น. (ตี 5) ของทุกวัน

## 2. สัตว์เลี้ยงตอบสนองต่อพฤติกรรมของผู้ใช้
- **หลอดพลังงานน้ำ (Water Energy Bar)** คำนวณจาก formula: `พลังงาน = จำนวนแก้ว x 12.5%` (สะสมสูงสุด 100% และไม่มีการลดลงระหว่างวัน)
- **เงื่อนไขสถานะและอารมณ์ของสัตว์เลี้ยง (กำหนดตามจำนวนแก้วที่ดื่มสะสม)**:
  - **ดื่มน้ำ 0 - 2 แก้ว (พลังงาน 0% - 25%)**: สัตว์เลี้ยงเหี่ยวเฉา ป่วย ใกล้ตาย
  - **ดื่มน้ำ 3 - 4 แก้ว (พลังงาน 37.5% - 50%)**: สัตว์เลี้ยงเริ่มเพลีย อ่อนแรง แลบลิ้น
  - **ดื่มน้ำ 5 แก้วขึ้นไป (พลังงาน 62.5% - 100%)**: สัตว์เลี้ยงสดชื่น ร่าเริง มีความสุข

## 3. ข้อจำกัดของทีม
- เวลาพัฒนาสั้น
- ใช้ Flutter ในการพัฒนาแอปพลิเคชัน
- เก็บข้อมูลสถานะและเวลาล็อกล่าสุดไว้ใน Local Storage บนเครื่อง (เช่น SharedPreferences / Hive)

## 4. สิ่งที่รู้แน่ ๆ ว่าไม่ทำในรอบนี้
- ไม่มีระบบลดพลังงานน้ำตามเวลาระหว่างวัน (Decay)
- ยังไม่ต่อ Backend หรือ Server ภายนอก
- ยังไม่มีระบบ Social / ดูเพื่อนร่วมกัน
- ยังไม่มีระบบซื้อของแต่งตัวสัตว์เลี้ยงเพิ่มเติม
