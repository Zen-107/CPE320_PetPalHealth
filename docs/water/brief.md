# Brief: ฟีเจอร์การบันทึกการกินน้ำ (Water Intake Tracking)

> เจ้าของ: เพื่อน A — โจทย์ตั้งต้นที่ Product agent อ่านก่อนเขียน requirements.md

## 1. ผู้ใช้ทำอะไรในฟีเจอร์นี้ และทำไมถึงอยากทำ
- ผู้ใช้กดบันทึกปริมาณการดื่มน้ำในชีวิตประจำวันเพื่อส่งเสริมสุขภาพการดื่มน้ำของตนเอง
- มีเป้าหมายคือดื่มน้ำอย่างน้อย 8 แก้วต่อวัน (1 แก้ว = 12.5% เพิ่มหลอดพลังงานสะสม)
- สามารถบันทึกแก้วน้ำเกิน 8 แก้วได้ (บันทึกแก้วสะสมไปเรื่อย ๆ แต่หลอดพลังงานจะแสดงผลสูงสุดที่ 100%)
- สามารถดู/พิมพ์รายงานสรุปรายเดือน (Monthly Report) ที่แสดงประวัติรายวันและค่าเฉลี่ยการดื่มน้ำต่อวันได้
- ระบบ Anti-Spam: อนุญาตให้กดบันทึกได้ **สูงสุด 1 ครั้ง (1 แก้ว) ต่อช่วงเวลา 5 นาที**
- ข้อมูลและหลอดพลังงานจะถูกรีเซ็ตเป็น 0 ตอน 05:00 น. (ตี 5) ของทุกวัน

## 2. สัตว์เลี้ยงตอบสนองต่อพฤติกรรมของผู้ใช้
- **หลอดพลังงานน้ำ (Water Energy Bar)** คำนวณจากสูตร: `พลังงาน = จำนวนแก้ว x 12.5%` (แสดงผลสูงสุด 100% และไม่มีการลดลงระหว่างวัน)
- **เงื่อนไขสถานะและอารมณ์ของสัตว์เลี้ยง (กำหนดตามจำนวนแก้ว)**:

| ช่วงพลังงาน (%) | จำนวนแก้วที่ดื่ม | สถานะและอารมณ์ของสัตว์เลี้ยง |
|---|---|---|
| **0% - 37.5%** | 0 - 3 แก้ว | เหี่ยวเฉา ป่วย ใกล้ตาย |
| **50% - 75%** | 4 - 6 แก้ว | เริ่มเพลีย อ่อนแรง แลบลิ้น |
| **87.5% - 100%+** | 7+ แก้วขึ้นไป | สดชื่น ร่าเริง มีความสุข |

## 3. ข้อจำกัดของทีม
- เวลาพัฒนาสั้น
- ใช้ Flutter ในการพัฒนาแอปพลิเคชัน
- เก็บข้อมูลสถานะ เวลาล็อกล่าสุด และประวัติรายวันไว้ใน Local Storage บนเครื่อง (เช่น SharedPreferences / Hive)

## 4. สิ่งที่รู้แน่ ๆ ว่าไม่ทำในรอบนี้
- ไม่มีระบบลดพลังงานน้ำตามเวลาระหว่างวัน (Decay)
- ยังไม่ต่อ Backend หรือ Server ภายนอกเพื่อซิงค์ข้อมูล
- ยังไม่มีระบบ Social / ดูเพื่อนร่วมกัน
- ยังไม่มีระบบซื้อของแต่งตัวสัตว์เลี้ยงเพิ่มเติม
