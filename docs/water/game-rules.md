## 1. ค่าหลัก

| ชื่อค่า (ใช้ในโค้ด) | ความหมาย | ค่า | หน่วย | อ้างถึง |
|---|---|---|---|---|

|---|---|---|
| เหี่ยวเฉา ป่วย ใกล้ตาย | 0 ถึง 3 แก้ว (รวม 0 และ 3, หรือ 0.0% ถึง 37.5%) | assets/images/pet_critical.png |
| เริ่มเพลีย อ่อนแรง แลบลิ้น | 4 ถึง 6 แก้ว (รวม 4 และ 6, หรือ 50.0% ถึง 75.0%) | assets/images/pet_tired.png |

## 3. เหตุการณ์และผลลัพธ์

| เหตุการณ์ | ค่าก่อน | ค่าหลัง | หมายเหตุ |
|---|---|---|---|
| กดบันทึกน้ำครั้งแรกของวัน | 0 แก้ว (0%) | 1 แก้ว (12.5%) | อ้าง AC-1 |
| ดื่มน้ำเพิ่มจาก 3 แก้ว เป็น 4 แก้ว | 3 แก้ว (37.5%) | 4 แก้ว (50.0%) | อ้าง AC-2 (สถานะเปลี่ยนจากป่วยเป็นเพลีย) |
| กดบันทึกน้ำซ้ำภายใน 3 นาทีหลังบันทึกครั้งล่าสุด | 2 แก้ว (25.0%) | 2 แก้ว (25.0%) | อ้าง AC-3 (บล็อกการบันทึก, แสดง Toast เตือน) |
| กดบันทึกน้ำหลังจากผ่านไป 5 นาที | 2 แก้ว (25.0%) | 3 แก้ว (37.5%) | อ้าง AC-4 (บันทึกสำเร็จ, อัปเดต Timestamp) |
| ข้ามเวลาไปถึง 05:00 น. ของวันใหม่ | 5 แก้ว (62.5%) | 0 แก้ว (0.0%) | อ้าง AC-5 (รีเซ็ตข้อมูลเป็น 0 อัตโนมัติ) |

## 4. พฤติกรรมที่ขอบเขต

| กรณี | ผลลัพธ์ |
|---|---|
| ผู้ใช้ดื่มน้ำสะสมเกินเป้าหมายสูงสุด (เช่น ดื่มสะสม 12 แก้ว หรือ 150%) | หลอดพลังงานแสดงผลหยุดอยู่ที่ 100% (สูงสุดตาม UI) แต่ตัวเลขจำนวนแก้ว (12 แก้ว) ยังคงสะสมและบันทึกเพิ่มขึ้นตามจริง |
| อุปกรณ์มือถือปิดเครื่องหรือแบตเตอรี่หมดข้ามคืนในช่วงเวลา 05:00 น. | เมื่อเปิดแอปขึ้นมาใหม่ ระบบตรวจสอบ Timestamp และทำการรีเซ็ตค่าจำนวนแก้วและพลังงานเป็น 0 ทันทีตามเงื่อนไขเวลา 05:00 น. ของวันใหม่ |
| ผู้ใช้พยายามกดรัวปุ่มบันทึกน้ำหลายครั้งติดกันภายในเสี้ยววินาที | ระบบจะบันทึกเพียงครั้งแรกครั้งเดียว และบล็อกการกดที่เหลือตามกฎ Anti-Spam 5 นาที |
| ผู้ใช้บันทึกน้ำก่อน 05:00 น. ไม่ถึง 5 นาที แล้วกดอีกครั้งหลังรีเซ็ต 05:00 น. (เช่น บันทึก 04:58 แล้วกด 05:01) | ห้ามกดซ้ำ 5 นาทียังนับต่อแม้ข้ามเวลารีเซ็ต 05:00 — บล็อกการบันทึกและแสดง Toast จนครบ 5 นาทีจากการบันทึกครั้งล่าสุด (ในตัวอย่างบันทึกได้ตั้งแต่ 05:03) |
| Toast แจ้งเตือน Anti-Spam แสดงขึ้น | Toast หายเองใน 2 วินาที |
| นาฬิกาเครื่องถูกตั้งย้อนกลับ จนเวลาปัจจุบันอยู่ก่อนเวลาบันทึกล่าสุด | แอปต้องไม่ crash นับเป็นวันเดียวกับการบันทึกล่าสุด และห้ามลบข้อมูล |
| ข้อมูลในเครื่องเสียหรือเก็บผิดชนิด | เริ่มใหม่เป็นค่าว่าง แอปห้าม crash |
