## 2. รีวิวโค้ดใน app/
โค้ดใน `app/lib/features/food/` และการเชื่อมโยงใน `app/lib/main.dart` / `app/lib/features/water/` ทำงานสอดคล้องกับ Acceptance Criteria และ game-rules.md อย่างถูกต้องสมบูรณ์
- **การประมวลผลโภชนาการ (AC-1, AC-2, EC-1):** `FoodController` และ `LocalMenuNutritionParser` ดึงข้อมูลจากตารางเมนูในเครื่องเทียบชื่อเมนู พร้อมรองรับช่วงตัวเลขคำนวณค่ากึ่งกลาง (Median) และเปลี่ยนเป็นฟอร์มกรอกแคลอรี่เอง (Default 300 kcal หากปล่อยว่าง) เมื่อเกิด Parsing Failure ภายใน 3 วินาที
- **รอบวัน 05:00 น. (AC-3, US-5):** `FoodLogic.logicalDay` และ `applyDayRollover` จัดการรอบตัดวันและประวัติย้อนหลัง 7 วันได้อย่างถูกต้อง
- **การจัดการโปรไฟล์และเป้าหมายแคลอรี่ (AC-4 ถึง AC-7):** `FoodLogic` บล็อกอายุทศนิยม (จำนวนเต็ม 1–120 เท่านั้น), คำนวณ Base Target ตามตาราง Reference Table และปรับเพิ่ม/ลด ±400 kcal ตามเกณฑ์ BMI (<18.5 และ ≥23.0)
- **UI แดชบอร์ดและแอนิเมชันสัตว์เลี้ยง (US-3, AC-8 ถึง AC-12, EC-2ถึง EC-4):** S-1 แสดงผลสอดคล้องกับสถานะพลังงาน หลอดสีแดงเมื่อเกิน >100 kcal พร้อมป้าย「อิ่มแล้ว」, แสดง CTA Banner ขนาดเท่าหลอดเดิมเมื่อข้ามโปรไฟล์โดยไม่มี Layout Shift, และจัดการ Toast「พอเถอะน้าคนดี」ด้วยกลไก Queue Replace ระยะห่าง 12px บน PetCharacter (CustomPainter ตามข้อตัดสิน OQ-1)
- **ชุดการทดสอบ (`app/test/food/`):** มีเทสต์รวมถึง 193 เทสต์ (Logic 64, Controller 53, Screens 76) ครอบคลุม AC, EC, ขอบเขต ±1, ข้ามวัน, ข้อมูลเสีย และผ่านทั้งหมด 100% (รวมทั้งแอป 603 เทสต์ผ่านหมด, `flutter analyze` ปราศจากปัญหา) รวมถึงผ่านการแก้ไข Bug ช่องพลังงาน overflow (BUG-FOOD-1) และตัวเลขบน CTA ถูกตัดที่ textScaler 1.5 (BUG-FOOD-2) เรียบร้อยแล้วในรอบที่ 2
